# 单词搜索、持久化排序与导入规则

Status: ready-for-agent

依据：2026-10-27 用户已确认方案；项目设计“本次维护”章节为完整规格。

## 决定

- 搜索忽略大小写，trim 后字面子字符串匹配四类字段；分类切换保留；导出跟随搜索。
- 搜索非空禁用重排；全部页无拖拽，随机仅在待记页。
- 拖入词固定前项 +1 / 首位 1，冲突后项顺延，首个不冲突项即停止；单 SQL 批量保存变化项。
- 数据库 v2；两个分类独立最大计数，只在提交后上调。普通编辑不改号。
- JSON v2 导出、v1/v2 导入；任一缺号整批按文件顺序，否则稳定按号升序。
- 采用重复导入词必须删旧建新 ID/序号，按规范化名称同步剩余卡片；单条点击顺序、批量剩余导入顺序，事务回滚。
- 词性 n/v/a；保留数字；源码/文档/测试交付，不打包。

## 验证

旧库迁移、排序同号/最小改写、单 UPDATE、事务与计数回滚、搜索/导出一致、拖拽组与取消/动画/边缘滚动、随机、重复导入新 ID/同步/批量回滚；全部现有回归及隔离原生窗口与 125%/150% 布局检查。
