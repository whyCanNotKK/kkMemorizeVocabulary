# 双击构建 Windows 安装包

用户要求根目录提供可双击的可执行文件，自动将当前项目构建成可在 Windows 双击安装的 EXE。

入口为 `BuildInstaller.exe`，可读源码保留于 `scripts/BuildInstaller.cs`，由 `scripts/build-launcher.ps1` 重建。调用 `build.ps1`，自动检查 Python 3.12 x64、补齐锁定依赖、缓存固定版本 Inno Setup 便携编译器，再生成并验证完整运行目录、ZIP 和单个 Setup.exe。

安装到当前用户目录，支持快捷方式、卸载与覆盖升级。安装程序始终保留独立的用户数据目录。构建显示进度、持久日志，失败非零退出；双击模式结束保留窗口，成功打开 dist。

验证：真实执行根目录入口的同一构建路径；安装至 artifacts 内隔离路径，显式隔离数据完成首次和重启冒烟；重复安装、快捷方式、卸载入口和卸载保留数据；不操作默认数据库。
