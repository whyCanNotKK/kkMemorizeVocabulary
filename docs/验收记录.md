## 已修复的打包问题

曾出现 `DLL load failed while importing QtCore: 找不到指定的程序`。依赖分析发现，打包工具从其他开发工具的 PATH 中收集了一份 ICU DLL，缺少 Qt 所需的未带版本号接口，覆盖了 Windows 内置接口的正常解析。

修复措施：打包时使用干净的 PATH；发布包排除外来的 ICU 和 API-set 替代文件；新增 `scripts/verify_release.py`，验证错误 DLL 不存在且包内代码与源码一致。修复后的 EXE 已完成首次保存与重启两次运行验证。
