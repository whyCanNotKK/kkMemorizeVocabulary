## 1. 项目目标

为个人开发一个启动方便、录入流畅、完全离线的 Windows 单词本。使用者手动输入英文单词、词性与中文释义，程序保存到 SQLite；复习时可以揭晓答案、标记已记下、设置重点，并查看自行录入的关联词。

核心目标是减少操作步骤：横向连续输入、键盘完成常用动作、原地纠错、即时保存状态。第一版交付源码以及包含 EXE 的完整程序文件夹，直接双击运行，无需另装 Python。

不提供联网词典、自动翻译、账号、云同步或发音。支持离线 JSON 导入导出及本次维护规定的十七天学习日程。

## 3. 使用对象与概念

- **主词**：主列表中的一个完整词条，具有名称、释义、关联词、重点和记忆状态。
- **释义**：一组“词性 + 翻译”。同一个词可以有多组释义，翻译可以包含换行。
- **关联词**：主词的附属内容，可以有多个，每个关联词也支持多组释义。它不单独进入主列表，不具有独立重点和记忆状态，也不会自动建立双向关联。
- **重点**：主词的布尔属性，亮星代表重点，灰星代表非重点。
- **已记下**：主词的布尔属性，决定其所属的待记/已记下列表。

## 4. 主窗口设计

窗口采用深色主题，上方为复习列表，下方为可折叠、自适应高度的录入区域。初始尺寸约 1040×820，最小尺寸 860×640；支持窗口缩放和 Windows 显示缩放。两个区域之间仅保留普通间隔，不使用可拖动分隔条。录入区展开时底部操作栏始终可见。

- 关联词在单词列缩进，其词性、翻译与主词采用同一列对齐；只有主词首行显示星标和操作。
- 选中主词、任一关联词或任一释义时，所属主词的全部可见行一起连续高亮；仍可对原先点击的单元格就地编辑。列表采用紧凑行距：展开时主词首行约28，关联词首行约32，后续释义行约21；差异只用于词前顶部留白，同词各条释义之间的留白一致，主词与关联词、各关联词之间使用更大的相同间隔，多行翻译按内容增高。隐藏主词仍约36。行高不受隐藏行表头的样式内边距限制。
- 列表和录入区均不设置状态提示区域，不显示“已保存”等常规成功提示；校验和写入错误使用保存按钮上方的非模态漂浮提示，带紧凑、不透明的深色背景以遮挡下方内容，仅留少量内边距和轻微圆角，不绘制明显边框。柔和文字居中、整体对齐保存按钮中心。提示从下向上淡入，停留约 2 秒后继续上浮淡出，不抢输入焦点、不占布局空间。连续触发时替换当前提示并重新计时；重复词提示可附下方居中的“查看已有词”入口。不提供撤销记忆标记入口，恢复待记使用已记下列表中的红色横杠。
- 标记记忆状态、重点、删除、编辑和揭晓/隐藏时保留当前滚动像素位置；数据减少时仅限制到新的滚动范围。刷新恢复选中项不自动滚动到它，避免揭晓上方词条时跳到下方旧选中项。新增词保存后的主动定位仍保留。
- 待记、全部、已记下各自在内存记录滚动位置，切换回来恢复原位置，首次进入和重启时从顶部开始。
- 新启动时所有词条默认隐藏，展开状态仅在内存中保留，不写数据库。
- 右上角眼睛只改变当前分类与搜索列出的全部词条整组，按实际显隐决定操作；混合显隐时反转该页独立记录。之后仍可逐词操作，新保存的主词仍默认展开。记录不持久化，每页启动默认隐藏。

### 4.2 遮罩与复习

- 隐藏状态下，每个主词只显示一条浅灰色圆角长条遮罩，跨越词性和翻译两列；关联词整体不显示，不为各条释义另画灰条。
- 鼠标左键单击灰色遮罩的实际圆角形状内部，一起显示主词全部词性、翻译及全部关联词；单击同一单元格内遮罩外的空白不揭晓。
- 非编辑状态下，Ctrl + 单击任一已显示翻译，隐藏所属主词的整组答案。
- 不设置“查看翻译”“收起翻译”文字按钮。

### 4.3 列表操作

| 状态 | 图标操作 |
| --- | --- |
| 待记 | 拖拽柄；圆圈：标记已记下；铅笔：编辑整组；垃圾桶：删除 |
| 已记下 | 拖拽柄；红色横杠：恢复待记；铅笔：编辑整组；垃圾桶：删除 |

全部页不显示拖拽柄，搜索非空时柄禁用；随机按钮仅在待记页星标表头显示。

所有图标带鼠标悬停说明和无障碍名称。星标点击后立即保存，非重点显示同形灰星。关联词不显示这些操作。

标记已记下后，词条从待记视图移出。删除主词前确认，并级联删除其全部释义与附属关联词。

### 4.4 就地编辑与整组编辑

- 双击主词/关联词名称：显示单行编辑器。
- 双击词性：显示统一的词性选择框。
- 双击翻译：显示多行编辑器。
- 就地编辑使用当前配置的保存快捷键提交，离开编辑器时也提交；Esc 取消。无效内容或写入失败保留编辑内容并提示，不能静默丢弃。
- 铅笔图标把词条完整载入底部，支持新增/移除关联词和释义；提供“保存修改”和“取消”。
- 就地编辑与底部整组编辑互斥。开始另一种编辑前先处理已有编辑；不能让旧表单覆盖更新后的词条。

### 4.5 JSON 导入导出

- “全局隐藏”右侧依次放置导入、导出图标按钮，悬停说明和无障碍名称分别为“导入单词”“导出当前页面所有单词”。搜索框放在紧凑全局隐藏图标左侧。
- 导出为 UTF-8 JSON，范围为当前分类及关键词共同筛选的主词，顺序与列表一致。页面内不在当前滚动视口中的词同样导出，隐藏/展开状态不影响完整词条信息。文件结构为 `{"format": "kkMemorizeVocabulary", "version": 2, "words": [...]}`。
- 每个已保存主词含 `text`、`important`、`learned`、`sort_order`、`senses`、`related`；每条释义含 `pos`、`translation`，每个关联词含 `text`、`senses`。数组顺序及翻译内部换行完整保留。数据库内部 ID 和时间戳由本机管理，快捷键和临时展开状态不在词条文件中。
- 导入先校验整个文件的格式版本、字段类型及完整词条内容；支持版本 1、2，排序号可缺省，存在时须为正整数。不支持的版本、损坏文件或无效词条在写库前报错。所有词都有排序号时稳定升序，否则按文件顺序；非重复词先在一个事务内保存，保留重点和记忆状态，按目标分类重新分配排序号。
- 仅按主词 `strip().casefold()` 判断重复；关联词同名不构成冲突。数据库已有或同一文件先前已导入的主词都视为重复，记录每次重复并继续处理其他词。
- 非重复词导入完成后，弹出可滚动的重复对比列表，每对左侧展示系统当前词条，右侧展示导入词条。整张卡片（含名称、释义、状态图标和空白）均可点击，键盘 Enter/空格同样可采用；点击即确定，左侧保留当前词，右侧事务覆盖完整词条，成功后立即移除该对卡片，保持滚动像素位置（必要时限制到新范围），无需“应用选择”。失败保留卡片，可重试；已成功处理的项目即时保存，关闭不撤销。
- 卡片不显示“第 x 条”、选择提示或单选圆点。首行依次展示亮/暗星标、主词，已记下时最右侧显示与主列表同样的绿色圆圈，悬停提示“已记住此单词”，未记下不显示。每条释义的词性使用统一大小的圆角方框，文字水平和垂直居中；框宽按全部支持词性中最长者的实际宽度加少量内部留白确定，主词和关联词使用相同尺寸，不显示横杠或补齐用空格。译文显示在框的右侧，保留内部换行和自动折行，同组译文统一起点；多行译文只对应一个词性框。关联词名称和全部释义统一缩进四个空格，不显示“关联词 x”等标题。此展示调整不改变数据库和 JSON 格式版本。
- 支持“全部使用左侧”和“全部使用右侧”，直接处理剩余项目并关闭弹窗；批量右侧覆盖使用一个事务，失败时全部回滚。全部处理完成自动关闭。关闭窗口保留尚未处理的原词，已导入新词和已确认的选择均保留。
- 同一主词多个重复项均展示；单条按实际点击顺序应用，批量按排序后的剩余候选顺序应用，最后一次右侧采用生效。右侧采用会在同一事务中删除原主词及附属内容，再创建新 ID 和目标分类末尾排序号，完整采用释义、关联词、重点和记忆状态。其余同名对比项按规范化名称同步最新系统词条和 ID。保留左侧不改变 ID、内容或排序。
- 导入前提交列表编辑并处理未保存表单，随后退出整组编辑，避免旧表单覆盖导入结果；文件选择取消不修改数据。导出前提交列表编辑，导出已保存词条。错误通过弹窗说明，任务结束显示导入数量及重复处理结果。

## 5. 录入表单

每个词的首行依次为 **单词输入框 → 词性下拉框 → 翻译多行输入框**，追加释义只增加词性与翻译，不重复单词输入框。

主词下方可添加多个关联词，关联词使用相同的横向录入结构。每个词始终至少保留一组释义输入框，初始词性未选择。

录入关联词时，在单词框左侧保留约 22 宽的位置，显示与列表相同的折角箭头；关联词单词框宽约 170，主词框仍为 192，整列总宽不变，词性和翻译列继续对齐。箭头只作关系提示，不接收焦点。

录入区标题固定为“添加单词”，不随编辑状态或未保存输入变化。录入区不再为每个词绘制独立背景框或焦点边框；新增关联词以水平分割线区分，不显示“关联词 1”等标题或编号，也不保留标题行占位；移除关联词按钮与该词的释义操作按钮放在同一行。单词、词性和翻译框保持相同高度（约 36），翻译仍支持 Enter 换行和内部滚动；词性框约 104 宽，剩余横向空间留给翻译，列标题与输入框对齐。

录入区展开高度完全按标题、列名、当前输入内容和底部操作栏的实际高度计算；单条释义的初始高度约 200，不再预留 310 的最低高度或下方空白。增加关联词或释义后自动增高，最多占窗口客户区高度的一半；未达到上限且内容能够完整显示时不出现外层滚动条，超过上限后只滚动输入内容，标题与底部操作栏固定可见。移除内容、清空表单或保存后自动缩回所需高度，窗口缩放时重新计算上限。高度只由内容和窗口尺寸决定，不支持手动拖动调整。

录入区最上方正中间提供大号 V 形收起按钮。点击后整个录入区向下收至仅保留标题与按钮的一行，释放的空间给单词表，按钮变为向上的折线；再次点击按当前内容恢复自适应高度、草稿、关联词、释义及可用的原输入焦点。折叠不触发保存或丢弃，不持久化，启动时默认展开。新增关联词、保存表单快捷键和编辑整组等需要录入区的操作会自动展开。折叠时关闭漂浮提示，关闭窗口和切换词条仍执行未保存内容保护。

- 全局“新增关联词”“移除末项关联词”按钮显示时带当前快捷键；没有关联词时隐藏“移除末项关联词”且不保留占位，添加关联词后显示，移除最后一个关联词或重置为空表单后再次隐藏。此项仅影响界面，不改变数据库或 JSON 版本。
- 各词有“增加释义”“删除释义”按钮，只有焦点所属的词显示这两个按钮的快捷键；删除释义仍只移除末项。只剩一条释义时隐藏“删除释义”按钮，不留占位；增加至两条及以上时重新显示。
- 新增关联词后聚焦新单词框；新增释义后聚焦新词性框。
- 移除已有内容的关联词或释义时确认，默认焦点在确认按钮，空格确认、Esc 取消；空白项直接移除。
- 每个词仅剩一条释义时，移除释义操作不执行；没有关联词时，移除关联词操作不执行。
- 底部同一行从左到右放“新增关联词”和“移除末项关联词”，右侧放取消、小星标和保存；“快捷键设置”移至顶部三个筛选按钮右侧。新增关联词不用加号前缀，全局操作按钮继续显示从数据库读取的快捷键。
- 新建词条默认重点点亮，保存成功后清空表单、恢复重点默认值、焦点回到主词框。
- 编辑已有词条时读取原重点值，取消时不修改数据库。
- Tab 正向移动、Shift+Tab 反向移动；翻译输入框 Enter 换行；星标获得焦点后可按空格切换。Ctrl+A 保留文字全选。
- 未保存输入切换到其他词条或关闭窗口时，提供保存/放弃/取消。

### 7.1 作用域与提示

- 释义操作只作用于当前焦点所在的词，没有词目标时不执行。
- 焦点在词的名称、词性、翻译或其释义按钮上，均视为该词获得焦点；其他词的释义按钮不显示快捷键。
- 全局操作按钮始终显示配置中的按键，不把默认字符串写死在按钮上。
- 快捷键在中英文输入状态下均应生效，不将失效原因限定为中文输入法。Qt 事件路径优先识别配置中的业务组合键，触发释义操作时直接读取实际焦点所属的词，不依赖缓存焦点状态。Windows 原生路径仅在自身窗口位于前台、无弹出窗口且未暂停快捷键时，在输入法处理前接收匹配按键；失去激活、打开设置或其他模态窗口时释放接收器。不匹配的按键直接传递，长按只触发一次，同次按键只触发一次，不修改输入法设置或其他程序的快捷键。
- 保存快捷键在列表编辑期间优先提交当前单元格，否则保存底部整组表单。
- 保存草稿后若立即进入列表就地编辑，延迟滚动不得打断当前编辑器。
- 重点快捷键只切换底部当前录入主词，不能用于关联词。
- 设置窗口打开时保留表单内容，关闭后恢复之前输入位置。捕获组合键期间暂停业务快捷键。

### 7.2 设置持久化和即时更新

设置窗口显示六项操作、当前快捷键、修改入口、恢复默认和完成按钮。点击修改后捕获新的单段组合，Esc 取消。

严格遵循以下顺序：

1. 校验组合键：需要 Ctrl 或 Alt 修饰，不允许重复，不占用 Ctrl+A/C/V/X/Z/Y、固定导航键及 Alt+F4。
2. 在事务内更新 SQLite，提交成功。
3. 从数据库重新读取完整快捷键配置。
4. 替换运行中的快捷键绑定，更新按钮文字和悬停提示，立即生效。

写库失败时不修改旧绑定；应用新绑定失败时恢复旧配置和绑定。启动时读取数据库；首次运行只为缺失设置写入默认值，不覆盖用户已有配置。

词性数字映射、Tab/Shift+Tab、Enter 换行、空格操作和 Ctrl+单击隐藏不在第一版可配置范围内。

## 8. 数据结构与一致性

### 8.1 位置与生命周期

- 默认数据库：`%LOCALAPPDATA%\kkMemorizeVocabulary\vocabulary.sqlite3`。
- 日志与数据库位于同一用户数据目录，程序更新不覆盖用户数据。
- 支持 `--data-dir <目录>`，测试和开发使用隔离目录。
- 使用 `PRAGMA user_version` 记录数据库版本，当前为5；拒绝更高版本。统一入口按顺序加载vocabulary/migrations/中的001至005独立SQL脚本，每步成功后提交版本号；失败仅回滚当前步骤，重启从最后成功版本继续。最终使用六字段学习表，保留词条分类排序、学习进度及设置；Repository不包含建表或升级SQL。
- 列表和卡片布局、即时选择、滚动记忆、录入区折叠和漂浮提示不增加持久化字段；本次 sort_order 字段需要上述 v1→v2 迁移。
- 交换文件独立使用 `version: 2` 并包含 sort_order，兼容导入 version 1，遇到未知版本拒绝导入。
- 启用外键及 WAL，所有聚合保存和删除均使用事务。

### 8.2 表设计

| 表 | 主要字段与约束 |
| --- | --- |
| words | id、text、normalized_text（唯一）、important、learned、sort_order（正整数、可重复）、created_at、updated_at；索引 learned/sort_order/id |
| related_words | id、word_id（级联外键）、text、position |
| senses | id、word_id 或 related_id（二选一所属）、pos、translation、position |
| settings | key（主键）、value（快捷键字符串、study_last_add_new_vocabulary最近抽词日期文本、study17.group_counter组号高水位） |
| memorize_vocabulary_17day | word_id（唯一级联外键）、group_number、stage（0为结束）、morning_done、afternoon_done、last_completed_on；阶段/最后完成日期索引 |

主词名称用 `strip().casefold()` 生成唯一检查值，保留用户原始大小写用于显示。词性与翻译分字段存储，翻译保留内部换行。顺序字段保持用户的释义和关联词排列。

### 8.3 保存与校验

- 主词必须有名称和至少一条完整释义，每个保存的关联词同样如此。
- 完全空白的额外行可忽略；有部分内容但未填完整时阻止保存并保留输入。
- 重复主词不创建、不覆盖，保留当前表单并提供定位已有词的入口；定位时切换全部列表、选中并滚动到目标。
- 关联词不受主词唯一性约束，不自动合并或建立双向关系。
- 整组编辑保持主词 ID，不把旧表单中的记忆状态覆盖到最新状态。
- 只有事务成功后更新界面；出错时保留输入与原持久化内容。

## 9. 模块边界与内部接口

- `domain`：WordEntry、RelatedWord、Sense、词性和默认快捷键定义，输入校验。
- `storage`：数据库初始化与迁移、读取聚合、保存聚合、删除、状态变更、两个分类的最大排序号、拖拽及随机排序、快捷键读取与写入；负责事务与 SQL。排序统一通过 batch_update_sort_orders 批量更新，事务提交后发布最大值。
- `transfer`：JSON 文件格式、严格校验、完整词条序列化及原子文件写入；`import_dialog`：重复词左右对比、逐条或批量选择及事务覆盖。
- `shortcuts`：规范化与校验、按作用域分发、设置生效和失败恢复；`native_shortcuts`：仅在 Windows 主窗口激活期间接收原生组合键，避开中文输入法拦截并在离开窗口或暂停时释放。
- `widgets`：词性选择框、释义输入行、主词/关联词输入组、确认窗口、图标绘制。
- `table`：视图行投影、自定义绘制、行高与换行、遮罩、点击/双击分发、就地编辑。
- `review_navigation`：共用方向键解析、受列表面板范围约束的键盘事件路由；将功能按钮上的导航交给当前WordTable.navigate_entries，不维护选择或业务状态。
- `window`：筛选及各页滚动记忆、表单编辑状态、焦点目标、设置窗口与提示。
- `learning`：北京时间操作快照、学习任务数据对象及阶段间隔计算；`study_page`：独立学习表格、刷新与上下午先后顺序操作，复用只读模式的 `table`；`storage` 提供生成、查询、完成学习任务的事务接口。
- `migration`：按版本读取UTF-8 SQL包资源，逐步事务执行并提交版本号；`migrations/`：历史建表与数据升级SQL。`storage`连接后调用此入口，升级失败关闭连接，成功后才读取业务状态。新增版本追加脚本并登记，不回改已发布脚本。
- `study_transfer`：独立学习进度JSON的无ID快照对象、完整文件校验与UTF-8原子文件保存；`storage`提供一致性导出快照及全量进度恢复事务，`window`复用词条重复选择界面协调两个导入阶段。
- `app`：命令行入口、用户数据目录、日志、主题、程序生命周期。

数据通过 Python 数据对象在层间传递，UI 不拼接 SQL；所有数据值使用 SQL 参数绑定。没有对外网络 API。
