# 项目设计说明

状态：当前实现规范 · 整理日期：2026-11-06

本文集中描述现行规则。开发操作见[开发指南](开发指南.md)，历史验证证据见[验收记录](验收记录.md)。

## 1. 目标与约束

kkMemorizeVocabulary 是本地离线单词本，提供词条整理、遮罩复习、十七天学习日程及任务历史。Windows 10/11 x64 为完整支持平台；macOS Apple Silicon 提供源码运行与未签名、未公证的 `.app` 试用分发支持。

- 单词、音标、词性、释义由使用者自行输入或导入，不内置词库，不提供联网词典、自动翻译、账号同步或发音。
- 数据保存在本机；普通记忆状态与十七天学习进度独立。
- 开发、测试和演示使用隔离数据目录，不写个人默认数据库。

## 3. 领域概念

| 概念 | 含义 |
| --- | --- |
| 主词 | 拥有独立ID、词名、可选音标、释义、关联词、重点、普通记忆状态及分类排序号的词条 |
| 释义 | 分开的词性与翻译；每个词至少一条已选词性的释义，译文可为空，保留多行正文及顺序 |
| 关联词 | 隶属于主词，可有音标及多条释义；不独立参与主词计数、抽词或记忆标记 |
| 重点 | 主词的星标，不决定学习阶段 |
| 已记下 | 普通列表分类标记，可恢复待记；不等同于十七天周期完成 |
| 学习轮次 | 一个阶段的上午、下午操作；整轮结算后推进阶段 |
| 任务记录 | 一个日期、时段的学习数量与用时汇总，不保存词级历史明细 |

## 4. 列表与编辑

### 4.1 布局、筛选与滚动

- 四个标签为待记、全部、已记下、十七天背单词，默认进入待记。普通页按分类、sort_order、ID升序，全部页先待记后已记；学习页按第6节排列。
- 搜索只出现在普通页，匹配主词、关联词及翻译，忽略大小写并清理查询首尾空白。搜索中禁止主词排序和随机排列；随机按钮仅在无查询的待记页显示。
- 有有效查询时，在搜索框内的清空图标左侧右对齐显示半透明的结果数量。数量随查询和当前页的结果同步更新，每个命中的主词只计一次，关联词和释义不另计。无匹配时显示0，空查询（包括纯空白）隐藏数量。沿用现有数据库及交换版本。
- 搜索文本改变（包括连续退格、清空按钮）时，仅跟随当前仍然有效的选中词及单元格：词仍在新结果中则保留选中并将整组滚入视口，键盘焦点仍留在搜索框；词一旦不在新结果中，立即取消该词的搜索定位，不跨查询记忆。之后清空或返回原查询也不自动重新选中该词，只有用户重新选择才建立新的跟随目标。无选中目标时回到结果顶部，不修改数据库排序。其他刷新仍按原滚动位置恢复。此项沿用现有数据库及交换版本。
- 主词及其关联词整组连续选中，单元格仍可单独定位编辑。词性、翻译横向对齐，关联词仅缩进词名；统一底色和译文侧竖线，不添加关联词外框或词带。
- 主词和关联词均可保存空音标。列表不增设音标列；音标显示以整个主词组为单位：鼠标悬停或当前键盘定位在主词、任一关联词或该组任一释义行时，该组所有已显示词名行的音标一起在单词列右端弱化显示。悬停与定位位于不同主词组时，两组同时显示；移出悬停后仍保留当前定位组。空音标保持空白，不改变答案显隐或展开隐藏关联词；词名优先占用宽度，音标仅使用剩余空间，互不覆盖。此项不改变数据库或交换格式。
- 表头允许拖动单词列、翻译列的右边界，学习页还可拖动周期列的右边界。收藏（组）/单词、词性/翻译之间锁定。拖动翻译右边界时保持周期列宽度，拖动周期右边界时优先调整周期和操作列，周期缩至标题所需宽度后可继续缩翻译列。拖动限制在当前列表视口内，单词至少34像素、翻译至少80像素，操作列至少保持该页默认宽度（待记/已记下188、全部154、学习88像素）。
- 可拖动的表头边界常显半透明双竖杠（每杠1像素宽、14像素高，居中），随列宽移动；锁定边界不画调整标记。
- 左键双击可调分隔线，将对应列尽量恢复到当前窗口的默认宽度：单词列206像素，翻译右边界恢复操作列默认宽度，周期右边界恢复周期列默认宽度。固定宽度的词性列随单词边界平移。空间不足时使用距离默认宽度最近的合法值，腾出空间后可再次双击完全恢复；锁定边界、标题文字、空白及右键双击不执行复位。
- 列宽只保存在本次运行内，刷新/切页保留实际宽度，关闭重开恢复默认，不写数据库或配置。窗口变窄时先缩翻译到80像素，再收回操作列超出默认值的空白，再缩周期列至最小宽度，最后缩单词列；再次放大只给翻译增加空间，不恢复此前被压缩的手动宽度。宽度变化重新计算换行行高并保留选择与滚动；单元格提交失败时不开始拖动或双击复位。
- 单词列按当前可用宽度优先展示完整词名：词名本身放不下时仅省略词名、不显示音标，悬停词名单元格提示完整词名；有音标时追加4个空格和完整音标。词名完整但放不下全部音标时，保留完整词名、在剩余空间省略音标，剩余空间不足省略号宽度则不画音标，悬停提示仅完整音标；两者均完整时无提示。音标仍只在悬停/键盘定位组显示。主词与关联词、隐藏答案均共用规则，重复释义空白词名单元格不提示。绘制和悬停按实时字体及列宽计算，拖动列宽或窗口收缩后立即更新；提示框按内容自然尺寸显示，保留4个空格，过长时仅受屏幕宽度限制换行，不省略内容。沿用现有数据库及交换版本。
- 普通三页分别记住滚动位置；学习页还记住当前词/单元格及整组选中状态。均只在本次运行内保留。刷新、切页和显隐恢复视图，不因旧选择强行滚动。
- 新增词保存后默认揭晓、选中并滚到底部；在已记下页新增时转到待记页。普通记忆状态切换后追加到目标分类末尾。
- 揭晓单词时按主词、全部释义和关联词的整组范围做最小滚动：已完整可见则不动，组尾越界仅下滚必要距离，组首在上方则回到顶部；整组超过视口时对齐组首。只滚动列表，不调整窗口。

### 4.2 显隐、复制与鼠标操作

- 启动默认隐藏答案，隐藏组只显示主词和灰色遮罩。遮罩左右范围保持原尺寸，点击范围垂直覆盖单元格整行；左/右键均揭晓整组、选中主词并聚焦列表，中键及左右空白不揭晓。
- 单独揭晓/隐藏通过共用入口处理；Ctrl+左键已显示翻译可隐藏所属整组。非空搜索禁止逐词隐藏，搜索结果初次显示或查询改变时临时揭晓。
- 眼睛及默认Ctrl+S作用于当前页、当前搜索结果的所有主词：全显示则全隐藏，全隐藏则全显示，混合/空页反转该页上次眼睛操作。普通三页共享逐词揭晓集合，四页的眼睛操作记录独立；清空查询保留这些词的最终显隐。
- 单词名称所在单元格整格（包括空白、音标及关联词箭头）支持单击复制完整词名、双击/右键编辑。后续释义行的空白词名格只支持右键整词复制。单击仍延迟系统双击间隔，双击取消复制；按住拖动不复制，关联词箭头保留拖动排序。已显示翻译仅实际文字单击复制完整正文（含换行），词性单击只选中。
- 词名可在隐藏时编辑，词性和翻译须先揭晓。右键或双击进入编辑；列表及其编辑框禁用Qt默认右键菜单，键盘剪贴板操作保留。
- 词名及音标只在单词列宽度不足时按第4.1节补充完整内容提示；词性、已显示释义及学习组号不提供重复内容的悬浮提示；遮罩、操作图标和拖动入口保留操作提示。
- 待记／已记下页的主词操作顺序为拖动、整词复制、编辑、记忆标记、删除。全部页从整词复制开始，后续顺序相同。学习页整词复制在首位，待完成词的记下按钮在其后。普通页编辑提示为「编辑单词」，记忆标记按当前状态提示「标记为"已记下"」或「标记为"待记"」。
- 右键点击星标／组号列、后续释义行的空白词名单元格或操作列空白处，复制所在行的主词或关联词。操作图标仍只响应左键。整词复制取得所选词的拼写、音标及有序释义，保持遮罩和编辑状态。成功提示「已复制：xxx的拼写、音标和所有释义」。已有词校验失败按缺少字段提示「整词复制失败：单词拼写不能为空」或「整词复制失败：释义词性不能为空」，并保留剪贴板。数据和交换版本沿用现有版本。

### 4.3 编辑与键盘导航

- 四个列表共用就地编辑。Enter（含数字键盘）保存并关闭编辑器，不继续触发列表记下；Shift+Enter在翻译内换行，Esc取消。失焦或保存快捷键同样提交。
- 编辑词名时，在词名编辑框下方悬浮音标框，主词/关联词及隐藏答案状态均支持；两个框之间切换焦点不提交，Tab从词名进入音标，Shift+Tab返回，音标Tab继续到下一字段。Enter、外部失焦或保存快捷键将词名和音标一起事务保存；Esc同时取消。失败保留两框输入并阻止后续操作。弹层保持在列表视口内，底部空间不足时移到词名框上方，不改变行高或数据库结构。
- F2编辑当前行所属词的释义；隐藏词先揭晓。Tab/Shift+Tab按词名→音标→各条词性/翻译→关联词→下一主词顺序连续编辑，词名和音标之间不提交，其余跨字段先保存；跳过操作列及重复空白，首尾不循环。
- 默认Ctrl+E将普通页当前选中行所属的主词整组载入下方编辑区，共用编辑图标入口：先提交行内编辑，失败则阻止；已有草稿沿用保存/放弃/取消提醒，编辑同一主词时保留草稿并展开聚焦。选中关联词或释义行也编辑所属主词；没有有效选中词时不执行，在十七天背单词页无效。快捷键可在设置中修改。
- 列表就地编辑通过任一现有方式提交时，清理拼写或译文首尾的空白（含换行）。译文为空且同一个词还有其他释义时，直接删除当前释义；仅剩一条时保留词性并保存空译文。关联词拼写为空时直接删除该关联词及其释义；主词拼写为空且无关联词时直接删除主词及其释义，沿用主词删除的学习记录和任务计数处理。有任何关联词的主词拼写为空时，在当前编辑框上方提示「单词拼写不可为空」。音标为空不触发删除。
- 删除后，Tab/Shift+Tab 跳过已删除的内容，继续到原编辑顺序中最近的可编辑字段。清空拼写删除主词时，若下方正编辑该主词，未修改的表单回到新增状态，有未保存输入则保留为新增草稿。提交失败保留编辑器和输入，阻止切页、刷新、导入导出等后续操作。学习页内容编辑共用主词数据，不抽词、不推进学习进度。
- 词名、音标和翻译编辑框支持用 Ctrl+V 粘贴整词，列表立即预览该词的拼写、音标、所有释义和条数，已有遮罩继续生效。编辑行消失时，将翻译编辑器移到该词最后一行。整词粘贴保留载荷中的空译文；粘贴后再手动清空当前译文时，按列表清空规则处理。跨字段 Tab 按新释义顺序定位并沿用现有提交时机。提交使用原始快照校验目标，失败保留预览和输入。提交前 Esc 关闭编辑器并恢复编辑前的内容、行数和原单元格。普通文本仍按 Qt 粘贴。
- W/S或上下箭头按主词导航，跳过释义及关联词行，首尾停止；无选择时选中视口内首个主词且保留滚动位置。空格切换当前整组答案，Ctrl+上下箭头只滚动。
- 列表面板内功能按钮聚焦时也可用W/S及上下箭头进入当前列表；输入框、编辑、拖动、弹层、忙碌状态不路由这些按键。
- 搜索框按下箭头进入首个结果；非空搜索的首个主词组按上箭头返回搜索框并将光标放末尾。W键及空搜索不触发返回搜索框。
- 长按回车、空格、F2及业务快捷键不重复触发；W/S和方向键允许连续导航。

### 4.4 排序与拖动

- 待记/已记下的主词拖动仅在无搜索时可用，全部页及学习页无主词拖动；随机仅重排当前待记词。
- 按关联词折角箭头拖动，可在同一主词内重排关联词整组；按已显示词性拖动，可在同一主词/关联词内重排释义。学习页同样支持这两种排序。
- 越过系统拖动阈值后才启动，采用150ms让位动画、内容跟随及边缘滚动，不绘制额外预览边框。Esc、失焦、刷新、超出范围或原位松开取消/不写入；隐藏答案或不足两项时不启动。
- 列表拖动前提交当前单元格，失败不启动；独立录入草稿不处理。写入失败恢复原顺序，排序不改变ID、内容、重点、记忆状态或学习进度。
- 分类排序号独立递增：新增/转入分类追加到末尾；主词拖动以“前项+1”为目标，仅顺延冲突项至首个无需调整的位置。批量更新共用事务接口，提交后才发布排序高水位。

## 5. 独立录入草稿与输入控件

- 普通页下方为添加/整组编辑区，默认展开，可居中箭头折叠；学习页隐藏该区域但保留草稿、编辑ID及折叠状态。高度随内容增长，最多半个客户区，超出只滚动表单内容，标题/底部按钮固定。
- 搜索、失焦、切页及列表编辑/排序不提示保存或清空草稿。仅关闭、主动清空/取消、载入另一主词、导入或删除正在编辑词等可能丢失/替换草稿的操作处理保护。
- 退出、载入另一主词或导入等需要处理未保存草稿时，共用“是否保留当前输入？”确认框，正文为“单词编辑区域还有未保存内容”；仅提供“保存”“放弃”，初始焦点在对话框，不聚焦任一按钮且无默认操作。右上角关闭或Esc均取消原操作并保留输入，初始Enter不保存或放弃。保存成功或明确放弃才继续原操作，保存失败仍保留草稿并阻止原操作。
- 新增显示“清空”，编辑显示“取消”。两者用共用紧凑确认框，仅提供确认/取消；默认Enter/Esc/关闭为取消，取消按钮与原操作按钮严格对齐。确认才丢弃输入、退出编辑并恢复新增表单，不改变已保存数据。
- 保存已有词的草稿时，以表单中的词名、音标、主词释义、关联词及重点完整覆盖数据库内容；列表修改独立即时入库，不回填或阻止草稿保存。表单保存后刷新列表。普通记忆状态、排序及学习进度保留数据库当前值。
- 每个主词/关联词的词名右方提供独立音标列，随草稿保存、清空及取消处理；列顺序为单词、音标、词性、翻译。单词列144像素，词性78像素，音标108像素；所需剩余空间从翻译列分配，主词/关联词各列对齐。表单内不显示“单词、音标、词性、翻译”列标题，保留区域标题与折叠按钮；输入框占位提示分别为“单词”（关联词为“关联词”）、“音标”、“词性”、“翻译（Enter 换行）”，使用半透明样式，不作为实际输入内容。
- 保存统一清理字符串首尾空白，保留内部空格、换行和顺序。主词与关联词必须有名称及至少一条已选词性的释义，译文允许为空；全空额外项可忽略，未选词性但填写译文的项阻止保存。表单清空译文仍保留该条词性及顺序，列表就地编辑按第4.3节处理。词性校验提示说明译文可留空。
- 主词以strip().casefold()判重，保留显示大小写；关联词同名允许，不自动建立全局或双向关系。新词默认重点、待记，保存后重置草稿、聚焦主词。
- 普通页展开的录入区始终显示新增关联词按钮。明确定位主词/关联词时插在该词之后（主词之后为第一个位置）；无明确目标（表单外失焦、表单内空白或其他无词组目标的表单按钮）时追加至关联词末尾。收起和学习页仍随整个表单隐藏。
- 表单内具体控件聚焦时，新增按钮显示“新增关联词 · 当前快捷键”；在表单外、对话框、窗口失活或点击表单空白没有具体控件聚焦时，按钮及提示均仅显示“新增关联词”。点击表单空白释放输入焦点并清除词组目标，但保留表单上下文；点击外部空白同时离开表单上下文。
- 展开的表单只要存在关联词就显示删除按钮，没有关联词则完全隐藏。明确定位关联词时显示“删除关联词 · 当前快捷键”；主词或其他无词组目标的表单控件聚焦时显示“删除末尾关联词 · 同一快捷键”。表单外、对话框、窗口失活或表单空白无具体控件聚焦时，显示不带快捷键的“删除末尾关联词”，点击删除当前末尾项；表单外快捷键仍不执行删除。两种删除共用原删除入口，末尾模式只把当前草稿顺序的最后一个关联词作为入参，非空确认、取消保护及删除后补位/上一词聚焦沿用原规则。
- 点击新增/删除按钮时保留直接来自词组输入的目标；已点击空白、其他无目标控件或离开表单后，不恢复之前的目标。新增和删除只修改草稿，保存时才入库；共用既有快捷键配置，不增加数据库或交换字段。
- 每条释义用加号在本行后插入，用垃圾桶删除本行；仅一条时删除禁用。快捷键按焦点所属释义操作，词名聚焦时新增追加、删除不执行。释义图标不参与Tab顺序。
- 主词和各关联词的首条释义在拖动柄左边显示整词复制图标，其他释义行保留同宽空位。同词有至少两条释义时，右键单词框、音标框和复制图标所在列下方的词内空白也可复制。两区域共用单行悬浮提示「整词复制 · Ctrl+1-9 · [鼠标右键]单词区域空白处」，右键图标与文字垂直居中对齐。复制读取当前草稿并沿用保存的必填规则，允许空音标、空译文和全空额外行。
- 词名、音标或翻译框 Ctrl+V 即时覆盖目标词的草稿和释义条数。翻译焦点所在行移除时聚焦该词最后一条翻译。在该词任一文本框按 Esc，恢复最近一次整词粘贴前的内容和行数。每个词独立保留一步，保存成功或重置草稿后清除。词性下拉保留原 Esc 行为。
- 表单可拖动关联词箭头及释义柄，只在所属词组内调整，不重建控件、不丢输入/光标；顺序随词条保存。预览快照保留透明背景并铺在面板底色上，不出现系统白底。布局变化同步更新Tab顺序。
- 翻译编辑框按换行/折行自适应，单行最小36像素；列表编辑框最长不超过视口，超长内部滚动；表单翻译随内容增长，由外层表单滚动跟随光标。
- 新获得焦点的可编辑文本/数字框取消自动全选并将光标移到末尾，随后可正常点击定位、选择及Ctrl+A；只读快捷键录制框除外。表单内空白/非交互标签将焦点转给表单面板并清除词组目标；其他主窗口空白将焦点转给窗口，保留按钮状态、Tab导航及快捷键。
- 词性为n./v./adj./adv./prep./pron./conj./interj./else，else末尾无点、中文说明为“其他”。列表双击词性打开独立浮层，按标签中心定位，完整显示9项；点击、数字1～9、n/v/a或Enter立即选择，Esc/外点取消，Tab继续编辑。表单保留组合框；a在形容词/副词间切换。
- 添加/编辑表单的词性为空时显示半透明“词性”占位提示，无“选择词性”提示；下拉只包含9个真实词性选项，数字及词性缩写靠左、中文说明靠右对齐（中文保持正常阅读顺序）。未选择时不自动填写首项；聚焦词性框或其下拉列表时，Esc/Backspace清空该框选择并关闭下拉，焦点留在词性框，不取消整组编辑；保存仍校验词性必填。列表就地词性浮层仍按Esc取消编辑；占位提示不写入数据库。
- 词性占位提示与其他输入框使用相同的PlaceholderText调色板颜色、字体和单次绘制，不叠加Qt默认标签，保持相同的半透明效果。

## 6. 十七天背单词

### 6.1 抽词、阶段与操作快照

- 操作日期/时段使用北京时间UTC+8，15:00起为下午。刷新或重新进入页面重新捕获快照，跨时段/跨日不自动更换；刷新提示为“刷新”。
- 上午仅当最近抽词日期不等于快照日期时抽新词；最多抽“每组单词数×每日新增组数”个待记主词，排除所有已参与过本功能的词，固定分组并使用全局递增组号。默认10词×3组，两项均可配置1～1000。
- 当天已有批次不补抽、不重新分组；抽到0词也保存最近日期，下午不抽。抽词、最近日期和组号高水位同事务；系统日期回拨仍按“不等于”处理。
- 阶段为1、2、4、7、15，stage=0表示周期结束并保留参与记录。阶段1直接进入任务，其余按距上次整轮完成日期至少1、2、3、8天到期，逾期进度保留。
- 上午完成置上午标记并清除下午标记；下午若上午未完成，只保存下午标记，若上午已完成则整轮结算：写实际快照日期、清空双时段标记并推进阶段，最终置0。普通已记下状态不受影响。

### 6.2 任务列表、进度与已完成词

- 待完成词按组号、主词ID升序。按钮排列为刷新、日期时段、秒表图标及实时用时、开始/暂停/继续；右侧依次显示“复习：剩余数/总数”“新词：剩余数/总数”和已完成显隐按钮。分子为大数字，分母保留弱化显示；有任务记录时总数读取记录，无记录时总数为对应待完成数。
- 当前锁定时段的任务记录状态为已完成时，隐藏顶部秒表图标、实时用时及开始/暂停/继续按钮，不保留其布局占位；刷新、重进页面或查看已完成词仍保持隐藏。切到未完成或尚无记录的时段时恢复显示。仅无待背词不视为完成，仍沿用原有按钮禁用规则；日期时段、刷新、剩余/总数及历史区域不受影响。不改变任务状态、计时结算或数据版本。
- 当前时段任务已完成且列表为空时，视口中央显示两行：“当前时段任务已完成！”和“在新时段点击[刷新图标]刷新，开启新任务”。图标沿用左上角刷新按钮的图形和尺寸，图标及其后的蓝色下划线“刷新”均可点击，悬停为手形光标，调用同一个刷新入口并重新捕获当前日期/时段；刷新失败保留当前完成提示。查看已完成词使列表非空时隐藏提示，隐藏已完成词后恢复；仅空任务或未完成记录不显示完成提示，仍沿用原空列表说明。不改变任务数据、计时规则、数据库或交换版本。
- 两个剩余数按当前时段待完成主词分别计数，采用较大、加粗的强调色；阶段1算新词，其余到期阶段算复习词。刷新、重启、查看已完成及任务完成后保持此含义；历史区域仍显示已背/总数。
- 回车先揭晓当前词，再按回车记下；鼠标记下使用同一入口，按钮悬浮提示显示“记下 · ”及回车键帽图标，图标与文字垂直居中对齐。成功后优先选中补位下一词，末项选前一词，全部完成清除选择；失败保留当前词及选择。
- 已完成显隐按钮默认空心圆，显示已完成时圈内显示勾号，提示为“显示已完成”/“隐藏已完成”。显示时将其按组号、ID追加在未完成词下，默认揭晓，无记下按钮且回车不能再次记下；查看它们不启动/继续计时。
- 已完成词依据现有时段标记和当日整轮完成日期查询，stage=1及当日刚推进至2归新词，其他归复习词。不新增词级历史，沿用现有进度的简化判断。
- 学习任务表首列标题为“组”，翻译与操作之间显示只读“周期”列。主词首行水平、垂直居中显示 `memorize_vocabulary_17day.stage` 的原始数值，隐藏答案时仍显示，后续释义行及关联词行留空。显示已完成词时同步显示结算后的阶段，周期结束显示 0。沿用 SQLite 10、普通词条 JSON 3、学习进度 JSON 6。
- 学习页允许共用的就地编辑、复制及关联词/释义排序，不提供普通记忆标记、整组编辑、删除或主词排序。

### 6.3 用时与任务记录

- 每个日期、时段最多一条任务汇总。点击开始、单独揭晓待完成词或记下首词可启动；仅进入、刷新、全局显隐及空任务不建记录。
- 运行/暂停只保存在内存，持久化任务状态只有0未完成、1已完成。重启或导入后，未完成任务以暂停状态载入，继续复用原记录。
- 单调时钟测量有效时间，四舍五入为整数秒（0.5进1），暂停后以保存的整数秒续计。开始/继续、手动/空闲/关闭/休眠/更换快照暂停时保存；最后一词完成属于自动暂停，与完成状态、结束时间同事务结算。
- 普通记下仅事务更新学习进度和数量，不写用时；导出使用已保存用时。保存采用累计值，不重复累加；失败冻结内存秒数供重试，异常终止可能丢失最后一次生命周期保存后的时长。
- 切标签、失焦、最小化继续计时。整个应用的点击、滚轮、键盘/输入法及原生快捷键操作重置60秒空闲，鼠标移动不算；超时暂停并累计至边界。恢复/唤醒不自动继续，待完成词的揭晓/记下可继续。
- 只有最后一次有效记下才置完成、记录实际结束时间；此前结束时间必须为空。删除最后待背词只暂停，不判完成。重复记下不重复计数，数据库失败回滚进度和记录。
- 删除词条只扣当前快照任务的对应总数，已背时也扣已背数；当日结算至stage=2仍归新词，计数限制在合法范围。其他历史不动，内部导入替换的删除重建不扣。无词级历史会使跨日遗留标记的扣减有误差。

### 6.4 历史区域

- 学习页下方为独立“背单词记录”面板，默认收起，本次运行内记住展开状态；高度最多半个客户区，表内滚动，普通页草稿状态不受影响。
- 面板标题栏右上角始终显示“合计 X 个单词”（收起时也显示），X直接统计memorize_vocabulary_17day全表条数，包含正在学习和stage=0已结束周期的主词，不按当前时段、到期状态、普通记忆分类或历史任务累计数量筛选，不计关联词。数字沿用上方复习/新词剩余数的22像素、700字重强调色；整行悬浮提示“包括已经背完的和正在背的”。进入页面、刷新、抽词、删除/清空及恢复进度后同步；沿用当前数据库及交换版本。
- 日期倒序，同日上午/下午成组、上午在上、下午在下。缺失时段只补显不落库，从最早记录补到今天；无记录只显示今天，15:00前不显示今天下午。
- 同一天的日期列跨上午、下午两行合并，日期在合并单元格内水平、垂直居中；今天仅有上午时保持单行居中。悬浮提示根据该行日期在本地计算并显示“周一”至“周日”。刷新及跨时段后重新按日期合并，分隔线位于整组底部；其他列仍逐时段显示。不改变数据库、交换格式或记录顺序。
- 列为日期、时段、开始时间、结束时间、记忆间隔、有效用时、复习词、新词、状态。数量显示“已背 / 总数”，斜杠居中，两侧数字各预留三位宽度，超过三位时在可用空间内对称扩展。历史以数据库快照为准，不实时叠加内存用时；顶部秒表旁的用时独立实时更新。
- 记忆间隔按任务日期及上午、下午顺序查找最近的前一个已完成时段，跳过缺失和未完成时段。用本时段的开始时间减去该时段的结束时间，四舍五入至整小时，显示“x h”。本时段有开始时间即可计算。缺少前一个已完成时段或开始时间早于该时段的结束时间时，显示破折号。历史数据变化时在本地重算并缓存于内存，不改变数据库或交换格式。
- 时段列仅显示居中的彩色图标：上午为金色太阳，下午为淡蓝色月亮；悬浮及无障碍文本分别为“上午”“下午”。沿用同一天合并居中的日期列、日期底色和组末分隔线，仅调整历史视图，不改变数据库及交换格式。
- 共用用时格式：不足60秒“x s”，不足3600秒“x m y s”，一小时起“x h y m”、不显示秒；分钟后的秒数为0时省略“0 s”，小时后的分钟数为0时省略“0 m”。总用时为0仍显示“0 s”。顶部实时计时与记录的有效用时共用此格式，不改变数据库及交换格式中的整数秒。起止时间显示“HH：MM”，使用略放大的全角冒号，小时和分钟各占等宽的两位数字。跨日保留MM-DD前缀，空值为破折号。
- 历史表的有效用时在单元格内整体居中，只排列实际显示的数值和单位。每个数值至少预留两个紧排数字的宽度并右对齐，h、m、s 的单位槽等宽。历史缺失行仍显示居中的破折号。开始时间、结束时间、有效用时、复习词和新词的单元格不显示悬浮提示。
- 开始时间和结束时间采用等宽的紧凑列，宽度按带跨日前缀的时间计算。腾出的空间分给有效用时、复习词和新词。
- 状态仅显示图标：补显缺失为灰叉，完成为绿勾，历史未完成为柔红叉，当前未完成为金色双三角快进。当前按锁定快照识别，暂停仍属当前任务；完成状态优先。悬浮提示分别为“未完成”“已完成”“未完成”“进行中”，无障碍文本继续区分四种状态。

- 数字键找不到选中词组或对应编号时静默返回，已存在的词按正常复制校验提示。
- 设置保留 Alt+1～9、Ctrl+1～9 及其数字键盘写法。启动时将占用保留键的动作恢复默认，被这些默认键挤占的动作优先改用自身默认，再用既有备用键。修复一次写入后绑定。设置拒绝保留或重复组合，提示原因并恢复录制框的上次有效值。
- 业务快捷键须含Ctrl或Alt，拒绝重复、文本/导航保留键及Alt+F4。先数据库提交，再读取配置并替换运行绑定；失败恢复原值。启动补缺失设置且避开旧键冲突；首次补入编辑选定单词快捷键时，若全局显隐仍为旧默认Ctrl+E且Ctrl+S未被占用，将其改为Ctrl+S。其他已保存配置保留，新动作默认键被占用时沿用既有备用键分配策略。只增加settings中的动作配置，不改变数据库结构或交换版本。
- Qt与Windows原生分发共用动作映射，原生仅在本窗口激活、无模态/下拉弹层且未暂停时接收，兼容中文输入法；失活释放，不影响其他应用，同次按键只执行一次。
- 快捷键修改即时保存，录制可Esc取消；恢复默认仅作用于快捷键。弹窗不自动聚焦首项，点击空白移除输入焦点、结束未确认录制，不显示重复说明/成功提示。
- 每日新增组数、每组词数修改有效值后立即一起入库，失败提示并将两项恢复为最近成功保存值；Esc/关闭保留已生效的修改。两项以紧凑居中数字框显示在“每日新背…组，每组…个新单词”一行，只影响之后的抽词。
- 设置窗口默认宽度约407像素、默认高度480像素（较640像素缩短四分之一），内容可垂直滚动，无“完成”按钮；所有配置修改直接生效并入库，删除仍需命令及二次确认。恢复默认快捷键按钮保持原尺寸，放在快捷键标题行最右端、底部对齐。沿用现有数据库及交换版本。
- “十七天背单词设置”“快捷键设置”“清空内容”三个大区块之间以半透明细横线及留白分隔，随内容一起滚动。
- 设置底部提供“清空内容”：说明“输入对应的确认信息删除对应的内容”，列出 `delete study record：删除学习记录。`、`clean vocabulary only：删除学习记录不包含的词汇。`、`remove all：删除所有学习记录和所有词汇。`。输入框仅绘制匹配前缀的半透明命令后缀，不自动填入；只有完整、区分大小写且无额外空白的三个命令之一才能启用确认。
- 删除前复用草稿清空确认窗口，明确删除范围与不可恢复性，默认Enter/Esc/关闭为取消。仅删除学习记录会保留词条及普通记忆状态；仅清理词汇按学习进度表（含stage=0）保留参与词；全部删除同时清空词条、学习进度和任务历史。每次操作一个事务，删除学习记录时同时移除settings中的study_last_add_new_vocabulary与study17.group_counter，保留快捷键及抽词偏好。成功后同步列表、历史、计时内存，不自动抽新词；删除正在编辑词时在警告中说明草稿将丢弃，确认成功才重置该草稿。
- 按钮提示使用当前实际快捷键，输入保护期间暂停业务快捷键。常规成功操作不显示状态栏；校验错误使用紧凑非模态浮动提示，重复词可定位已有词。

## 8. 数据结构与一致性

### 8.1 当前版本与存储

| 类型 | 当前版本 |
| --- | --- |
| SQLite | 10（由migration.SCHEMA_VERSION定义） |
| 普通词条JSON | 3（transfer.VERSION） |
| 学习进度JSON | 6（study_transfer.VERSION） |

默认数据目录为Windows `%LOCALAPPDATA%\\kkMemorizeVocabulary`，macOS `~/Library/Application Support/kkMemorizeVocabulary`；数据库为vocabulary.sqlite3，日志同目录。`--data-dir`可指定隔离目录。退出后复制数据目录可完整备份；更新/卸载保留个人数据。

### 8.2 表与约束

| 表 | 字段及用途 |
| --- | --- |
| words | id、text、phonetic（非空文本，默认空串）、normalized_text唯一、important、learned、sort_order正整数、created_at、updated_at；分类/排序号/ID索引 |
| related_words | id、级联word_id、text、phonetic（非空文本，默认空串）、position |
| senses | id、word_id或related_id二选一、pos（非空词性）、translation（非NULL文本，默认空串）、position |
| settings | key/value；快捷键、本机抽词偏好、最近抽词日期及组号高水位 |
| memorize_vocabulary_17day | word_id级联主键、group_number、stage、morning_done、afternoon_done、last_completed_on；阶段/最后日期索引 |
| study_task_history | id、task_date、afternoon、started_at、ended_at、duration_seconds、status、new_total、review_total、new_done、review_done |

- 学习阶段仅为0/1/2/4/7/15；阶段1最后完成日期为空，其余非空；双时段不能同时为1，stage=0清空双标记。
- 学习设置键为study17.words_per_group、study17.groups_per_day、study_last_add_new_vocabulary（YYYY-MM-DD）及study17.group_counter；删除词条不回收组号。
- 设置批量清理不单独新增字段或迁移；删除学习记录的两种命令在同一事务清除进度、历史及最近抽词日期/组号高水位。
- 任务日期/时段唯一，afternoon为0上午/1下午，status为0未完成/1完成；数量、整数秒非负，已背数不超过总数。未完成结束时间为空，完成必有结束时间。
- 任务起止时间为带+08:00、精确到秒的北京时间文本，任务日期来自锁定快照，允许起止跨日；有效用时不由时间差计算。任务汇总无词条外键或词级明细。

### 8.3 迁移与事务

- 按001～010包内UTF-8 SQL脚本顺序升级，每步BEGIN IMMEDIATE持锁后重读版本，成功提交user_version；失败只回滚当前步骤，重启续迁，拒绝更高版本。失败关闭连接，禁止进入业务读取。
- v9→v10将主词和关联词释义的旧词性代码“其他”更新为else，不改变释义ID、内容、顺序或学习进度。普通JSON 3、学习JSON 6保持不变，旧代码“其他”作为兼容别名在导入/保存时统一转为else，新的界面及数据库输出使用else。
- v8→v9事务重建senses，保留ID、归属、词性、译文、顺序、外键及索引，为translation设置空串默认值并为pos增加非空白约束；空译文使用空字符串，不使用NULL。普通JSON 3、学习JSON 6保持不变：字段及类型未变，仅允许translation字符串为空，仍拒绝缺字段、NULL及非字符串，兼容已有文件。
- v7→v8为主词及关联词追加phonetic，旧数据默认空串；保存清理首尾空白，导入严格要求字符串（允许空串）。普通JSON升至3，学习JSON升至6，继续仅接受最新版本。
- 历史步骤依次处理基础词条、分类排序、学习表、最近抽词日期、六字段学习模型、任务历史、整数秒。v6→v7将毫秒四舍五入为秒，保留其他数据；旧库不补造不存在的任务历史。
- 新增迁移只追加脚本，不修改已发布脚本。以sqlite3.complete_statement分句执行，不用会隐式提交的executescript；SQL脚本随包交付并验证一致。
- 所有数据值参数绑定，聚合保存、删除、排序及学习更新使用事务。UI仅在成功后更新；词条导入删除重建时同步迁移旧学习进度到新ID。
- 列表清空后自动删除沿用现有表、外键和任务计数规则。SQLite 10、普通文件 JSON 3、学习文件 JSON 6 和剪贴板 JSON 1 保持不变。

### 8.4 JSON交换

- 整词剪贴板是独立的普通文本 JSON 协议 `kkMemorizeVocabulary.word` v1，仅含格式、版本、`text`、`phonetic`、`senses`（每项 `pos`、`translation`）。带本协议标识但版本或结构无效时拒绝粘贴并提示，其他内容走原生粘贴。SQLite 10、普通文件 JSON 3、学习文件 JSON 6 沿用现有版本。

- 两种文件只接受各自当前实现的最新版本，拒绝旧版/未知新版；完整校验格式、字段、类型及内容后才处理草稿或写库，UTF-8文件使用临时文件原子替换。
- 词条文件格式为kkMemorizeVocabulary，包含words；每词包含text、phonetic、important、learned、senses、related及可选sort_order；每个关联词包含text、phonetic、senses。translation必须为字符串但可为空，名称和词性仍必填。释义/关联词数组顺序及正文保留，不交换本机ID或时间戳。重复对比包含音标。
- 学习文件格式为kkMemorizeVocabulary.study17，包含words、study_records、study_settings、task_history。进度以strip().casefold()词名绑定，词条与进度一一对应；历史包含全量汇总及原ID，校验ID/日期时段唯一、状态/结束时间与数量关系。
- 学习导出在同一读快照获取全部参与词（含未来到期和周期结束词）、进度、最近抽词日期、组号高水位及历史，不写入运行中用时。本机抽词偏好不参与交换。

### 8.5 导入流程

- 普通页导出当前分类/搜索的全部主词（含视口外），可识别词条或学习文件；学习页只接受学习文件。无效结构/内容/编码/版本在普通入口统一提示“数据结构不合法，导入失败”，实际读写错误保留原因。
- 合法学习文件先提供“导入单词和进度”“仅导入单词”“取消”，已有进度或任务历史时明确整体覆盖；取消不改数据/草稿、不切页、不抽词，不重复打开文件选择器。
- 词条先导入非重复项，再逐条/批量比较重复主词。清理首尾空白后，拼写、音标、顺序化释义/关联词、重点和记忆状态全相同则跳过；比较区分大小写，不考虑ID、排序号或时间戳。
- 排序号全有时稳定升序，否则按文件顺序；导入新增词追加到目标分类，主词仅按规范化名称判重。对比卡片左侧保留本机，右侧即时删除重建新ID；同名卡片同步最新内容，批量右侧采用在一个事务按候选顺序执行，最后采用者生效。关闭保留已处理项及未处理的本机词。
- 全量恢复前暂停旧任务。词条阶段之后，独立事务整体替换学习进度、任务历史及相关学习设置；失败一并回滚此阶段，已导入词条保留并说明。仅导入单词不替换进度/历史。
- 恢复成功清除旧计时内存，按当前日期/时段读取任务但不抽词，未完成记录以暂停载入；仅词条刷新原快照，不额外推进学习。
- 文件/数据库耗时处理在后台独立连接执行，半透明全窗口遮罩阻止输入、重复触发及关闭，主线程维持绘制；文件选择、确认及对比阶段可交互。任务结束/失败移除遮罩，后台不访问Qt控件。

## 9. 模块边界与内部接口

- `domain`：WordEntry、RelatedWord、Sense、词性和默认快捷键定义，输入校验。
- `storage`：数据库初始化与迁移、读取聚合、保存聚合、删除、状态变更、两个分类的最大排序号、拖拽及随机排序、快捷键读取与写入；负责事务与 SQL。排序统一通过 batch_update_sort_orders 批量更新，事务提交后发布最大值。
- `transfer`：JSON 文件格式、严格校验、完整词条序列化及原子文件写入；`import_dialog`：重复词左右对比、逐条或批量选择及事务覆盖。
- `word_clipboard`：单词内容校验和独立剪贴板协议；`word_paste`：限定文本框 Ctrl+V/Command+V 的 Qt 适配。`table` 维护行内预览及原始快照，`WordBlock` 负责表单草稿更新与撤回，`window` 路由复制并提示，`storage` 一次事务替换目标词及其释义。SQLite 10、普通文件 JSON 3、学习文件 JSON 6 和剪贴板 JSON 1 沿用现有版本。
- `busy_overlay`：全窗口半透明遮罩、旋转指示、输入保护及后台任务等待，只在界面线程绘制/处理控件；`transfer_jobs`：后台任务独立Repository连接的生命周期及排序高水位同步，返回普通数据对象，不访问Qt控件。
- `shortcuts`：规范化与校验、按作用域分发、设置生效和失败恢复；`native_shortcuts`：仅在 Windows 主窗口激活期间接收原生组合键，避开中文输入法拦截并在离开窗口或暂停时释放；其他平台只使用Qt窗口快捷键。
- `widgets`：搜索框及结果数量显示、词性选择框、释义输入行、主词/关联词输入组、确认窗口、图标绘制。搜索结果数量由`window`从当前页筛选结果提供。
- `table`：视图行投影、自定义绘制、行高与换行、遮罩、点击/双击分发、就地编辑。
- `table_style`：仅负责统一列表底色、选中底色、分隔线和译文侧分组竖线；接受现有Qt表格投影与绘制矩形，不维护业务状态或处理事件，不依赖`table`及页面/存储模块。
- `table_header`：统一处理可调分隔线的命中、拖动及左键双击复位；默认尺寸、最小宽度、合法区间、窗口收缩分配、运行内宽度记忆及换行行高由`table`协调，不读写数据库。此轮不改变SQLite或JSON版本。
- `word_name_editor`：列表词名输入及其下方音标浮层的几何、焦点归属和生命周期；`table`协调键盘及一次提交两项，`window`将二者写入同一次聚合保存，不单独追加数据迁移。
- `review_navigation`：共用方向键解析、受列表面板范围约束的键盘事件路由；将功能按钮上的导航交给当前WordTable.navigate_entries，不维护选择或业务状态。
- `input_focus`：主窗口及所属对话框的输入焦点策略，新聚焦输入定位末尾，主窗口按钮在空白点击后释放焦点；不处理词条、保存、选择导航或快捷键业务。
- `form_focus`：区分表单内输入、操作控件、空白与表单外焦点，维护表单操作上下文并通知空白点击；不选择关联词或修改草稿。`window`据此决定按钮提示、插入位置与具体/末尾删除目标。
- `pos_picker`：词性浮层的完整选项、屏幕内定位、选择/取消信号及共用词性按键解析；不调用窗口或数据库，列表编辑代理负责提交，底部PosCombo复用按键解析。
- `draft_reset_dialog`：清空/取消编辑共用的模态确认、默认取消及原按钮位置对齐；不修改表单或数据库，由窗口在确认后重置输入。
- `unsaved_input_dialog`：处理未保存草稿的共用模态选择，仅有保存/放弃，初始不聚焦按钮，关闭/Esc取消；由window在明确选择后保存或丢弃输入，不读写数据库。
- `cleanup_input`：设置清空命令的半透明后缀绘制，不修改文本、不提供自动补全；`shortcuts.SettingsDialog`负责命令校验及共用删除警告，`window`协调成功后的草稿、计时和列表刷新，`storage.clear_content`负责事务删除及抽词状态清理。
- `drag_reorder`：主词及关联词拖动共用的插入位置计算、动画时长、预览边框和边缘滚动规则，不依赖业务窗口或存储。
- `form_reorder`：关联词输入组及词内释义行共用的拖动事件、快照预览和范围保护，不重建输入控件、不读写数据库；窗口编排blocks排序，WordBlock处理释义行排序并通知更新Tab顺序，拖动期间暂停业务快捷键，结束恢复原暂停状态。
- `window`：筛选及各页滚动记忆、表单编辑状态、焦点目标、设置窗口与提示。
- `learning`：北京时间操作快照、学习任务/历史数据对象及阶段间隔计算；`study_page`：独立学习表格、刷新、计时按钮与上下午先后顺序操作；`storage` 提供生成、查询、完成学习任务及历史汇总的事务接口。
- `study_completion`：完成任务后的两行提示、可点击刷新图标和链接文字及视口居中定位，只发出刷新请求；是否显示和实际刷新由`study_page`决定，不读写数据库。
- `study_timer`：单调时钟累计、应用空闲及Windows电源事件（仅Windows）、内存运行/暂停状态，持久化通过Repository；其他平台依赖单调时钟和空闲检测。`study_history`：只读历史表格、缺失时段投影、日期分组及独立折叠面板，不拼接SQL、不生成任务。
- `migration`：按版本读取UTF-8 SQL包资源，逐步事务执行并提交版本号；`migrations/`：历史建表与数据升级SQL。`storage`连接后调用此入口，升级失败关闭连接，成功后才读取业务状态。新增版本追加脚本并登记，不回改已发布脚本。
- `study_transfer`：独立学习进度JSON的词名绑定快照及带ID的任务历史、完整文件校验与UTF-8原子文件保存；`storage`提供一致性导出快照及全量进度恢复事务，`window`复用词条重复选择界面协调两个导入阶段。
- `app`：命令行入口、用户数据目录、日志、主题、程序生命周期。

数据通过 Python 数据对象在层间传递，UI 不拼接 SQL；所有数据值使用 SQL 参数绑定。没有对外网络 API。

## 10. 开发运行与分发

源码环境、隔离数据目录、测试、构建命令及辅助工具统一见[开发指南](开发指南.md)。Windows构建交付完整程序目录、便携ZIP和安装程序；macOS在Apple Silicon主机上构建`.app`与ZIP，首轮不签名、不公证。发布页实际附件由维护者选择上传，不把源码ZIP或构建启动器当成安装包。

日常构建默认执行`tests/build-smoke.txt`中的关键检查，覆盖持久化、迁移、导入导出、学习进度和代表性界面交互，失败立即停止构建。完整界面参数矩阵用于显式开发回归，可通过`build.ps1 -FullTests`随构建执行；默认双击构建启动器不运行全量矩阵。两种模式均执行成品源码/SQL一致性检查及依赖检查。此构建策略不改变程序行为、数据库或交换格式版本。

## 11. 验收标准

- 词条聚合、多释义/关联词、唯一校验、级联删除、保存/导入/排序失败回滚及重启恢复。
- 四页鼠标/键盘、遮罩显隐、复制/编辑、Tab/F2导航、输入法、拖动/取消/滚动、独立草稿覆盖及确认保护、音标双目标显示、允许/锁定的列宽边界。
- 快捷键提交先于生效、冲突拒绝、失败回退、改键重启保留及原生路径去重。
- 抽词固定批次/零词、时段边界/快照、逾期/阶段结束、分类计数、已完成词展示与重复记下保护。
- 整数秒取整、暂停/继续/空闲/关闭/休眠、用时写入频率、历史静态与顶部实时分离、四态图标及缺失补显。
- 各版本迁移、迁移断点/失败、JSON最新版本及完整校验、词条与进度覆盖/取消/仅词条、历史往返及事务失败。
- 默认/最小窗口、125%和150%缩放不重叠；EXE离线无控制台启动，隔离首次保存/重启、更新/卸载保留数据。
- 成品模块和SQL资源与源码一致，不混入外来ICU/API-set DLL。测试数据库与个人数据分离。

具体测试数量、截图及成品验证结果只记录在[验收记录](验收记录.md)，历史条目不覆盖当前规范。

## 12. 文档与维护

- 需求变化先修改对应设计章节及数据版本策略，再改实现；直接维护现行规则，不累计重复的“本次维护”段落或保留互相覆盖的旧说明。
- README面向使用者，保持简介、安装及自备词汇说明；操作细则留在本文，开发命令留在开发指南，验收只记录新证据。
- 构建输出与源码/虚拟环境/测试数据分离；程序更新保留数据目录，完整备份先退出程序。
- Qt使用Windows自带ICU，构建限定项目虚拟环境及Windows依赖路径。新增表、交换字段或版本策略需补迁移/严格校验/回滚及打包资源验证。
