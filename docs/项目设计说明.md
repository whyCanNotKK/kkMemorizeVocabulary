# 项目设计说明

状态：当前实现规范 · 整理日期：2026-11-05

本文集中描述现行规则。开发操作见[开发指南](开发指南.md)，历史验证证据见[验收记录](验收记录.md)。

## 1. 目标与约束

kkMemorizeVocabulary 是 Windows 本地离线单词本，提供词条整理、遮罩复习、十七天学习日程及任务历史。

- 单词、词性、释义由使用者自行输入或导入，不内置词库，不提供联网词典、自动翻译、账号同步或发音。
- 数据保存在本机；普通记忆状态与十七天学习进度独立。
- 开发、测试和演示使用隔离数据目录，不写个人默认数据库。

## 2. 技术环境

| 项目 | 约定 |
| --- | --- |
| 平台 | Windows 10/11 x64，中文界面 |
| 运行时 | Python 3.12 x64、PySide6 / Qt Widgets |
| 持久化 | SQLite，启用外键与WAL |
| 验证 | pytest、pytest-qt、临时数据库及隔离源码/成品冒烟 |
| 分发 | PyInstaller目录式程序、便携ZIP、Inno Setup安装程序 |

依赖版本以requirements.lock.txt为准。安装包自带运行环境，运行不依赖网络。

## 3. 领域概念

| 概念 | 含义 |
| --- | --- |
| 主词 | 拥有独立ID、词名、释义、关联词、重点、普通记忆状态及分类排序号的词条 |
| 释义 | 分开的词性与翻译；每个词至少一条完整释义，保留多行正文及顺序 |
| 关联词 | 隶属于主词，可有多条释义；不独立参与主词计数、抽词或记忆标记 |
| 重点 | 主词的星标，不决定学习阶段 |
| 已记下 | 普通列表分类标记，可恢复待记；不等同于十七天周期完成 |
| 学习轮次 | 一个阶段的上午、下午操作；整轮结算后推进阶段 |
| 任务记录 | 一个日期、时段的学习数量与用时汇总，不保存词级历史明细 |

## 4. 列表与编辑

### 4.1 布局、筛选与滚动

- 四个标签为待记、全部、已记下、十七天背单词，默认进入待记。普通页按分类、sort_order、ID升序，全部页先待记后已记；学习页按第6节排列。
- 搜索只出现在普通页，匹配主词、关联词及翻译，忽略大小写并清理查询首尾空白。搜索中禁止主词排序和随机排列；随机按钮仅在无查询的待记页显示。
- 主词及其关联词整组连续选中，单元格仍可单独定位编辑。词性、翻译横向对齐，关联词仅缩进词名；统一底色和译文侧竖线，不添加关联词外框或词带。
- 普通三页分别记住滚动位置；学习页还记住当前词/单元格及整组选中状态。均只在本次运行内保留。刷新、切页和显隐恢复视图，不因旧选择强行滚动。
- 新增词保存后默认揭晓、选中并滚到底部；在已记下页新增时转到待记页。普通记忆状态切换后追加到目标分类末尾。
- 揭晓单词时按主词、全部释义和关联词的整组范围做最小滚动：已完整可见则不动，组尾越界仅下滚必要距离，组首在上方则回到顶部；整组超过视口时对齐组首。只滚动列表，不调整窗口。

### 4.2 显隐、复制与鼠标操作

- 启动默认隐藏答案，隐藏组只显示主词和灰色遮罩。遮罩左右范围保持原尺寸，点击范围垂直覆盖单元格整行；左/右键均揭晓整组、选中主词并聚焦列表，中键及左右空白不揭晓。
- 单独揭晓/隐藏通过共用入口处理；Ctrl+左键已显示翻译可隐藏所属整组。非空搜索禁止逐词隐藏，搜索结果初次显示或查询改变时临时揭晓。
- 眼睛及Ctrl+E作用于当前页、当前搜索结果的所有主词：全显示则全隐藏，全隐藏则全显示，混合/空页反转该页上次眼睛操作。普通三页共享逐词揭晓集合，四页的眼睛操作记录独立；清空查询保留这些词的最终显隐。
- 单击词名或已显示翻译的实际文字，延迟系统双击间隔后复制完整文本（含换行）；双击取消复制并编辑。词性单击只选中；空白、箭头及按住词名/翻译拖动均不复制。
- 词名可在隐藏时编辑，词性和翻译须先揭晓。右键或双击进入编辑；列表及其编辑框禁用Qt默认右键菜单，键盘剪贴板操作保留。
- 词名、词性、已显示释义及学习组号不提供重复内容的悬浮提示；遮罩、操作图标和拖动入口保留操作提示。

### 4.3 编辑与键盘导航

- 四个列表共用就地编辑。Enter（含数字键盘）保存并关闭编辑器，不继续触发列表记下；Shift+Enter在翻译内换行，Esc取消。失焦或保存快捷键同样提交。
- F2编辑当前行所属词的释义；隐藏词先揭晓。Tab/Shift+Tab保存后按词名→各条词性/翻译→关联词→下一主词顺序连续编辑，跳过操作列及重复空白，首尾不循环。
- 提交失败保留编辑器和输入，阻止切页、刷新、导入导出等后续操作。学习页内容编辑共用主词数据，不抽词、不推进学习进度。
- W/S或上下箭头按主词导航，跳过释义及关联词行，首尾停止；无选择时选中视口内首个主词且保留滚动位置。空格切换当前整组答案，Ctrl+上下箭头只滚动。
- 列表面板内功能按钮聚焦时也可用W/S及上下箭头进入当前列表；输入框、编辑、拖动、弹层、忙碌状态不路由这些按键。
- 搜索框按下箭头进入首个结果；非空搜索的首个主词组按上箭头返回搜索框并将光标放末尾。W键及空搜索不触发返回搜索框。
- 长按回车、空格、F2及业务快捷键不重复触发；W/S和方向键允许连续导航。

### 4.4 排序与拖动

- 待记/已记下的主词拖动仅在无搜索时可用，全部页及学习页无主词拖动；随机仅重排当前待记词。
- 按关联词折角箭头拖动，可在同一主词内重排关联词整组；按已显示词性拖动，可在同一主词/关联词内重排释义。学习页同样支持这两种排序。
- 越过系统拖动阈值后才启动，采用150ms让位动画、内容跟随及边缘滚动，不绘制额外预览边框。Esc、失焦、刷新、超出范围或原位松开取消/不写入；隐藏答案或不足两项时不启动。
- 列表拖动前提交当前单元格，失败不启动；独立录入草稿不处理。写入失败恢复原顺序，排序不改变ID、内容、重点、记忆状态或学习进度。
- 分类排序号独立递增：新增/转入分类追加到末尾；主词拖动以“前项+1”为目标，仅顺延冲突项至首个无需调整的位置。批量更新共用事务接口，提交后才发布排序高水位。

## 5. 独立录入草稿与输入控件

- 普通页下方为添加/整组编辑区，默认展开，可居中箭头折叠；学习页隐藏该区域但保留草稿、编辑ID及折叠状态。高度随内容增长，最多半个客户区，超出只滚动表单内容，标题/底部按钮固定。
- 搜索、失焦、切页及列表编辑/排序不提示保存或清空草稿。仅关闭、主动清空/取消、载入另一主词、导入或删除正在编辑词等可能丢失/替换草稿的操作处理保护。
- 新增显示“清空”，编辑显示“取消”。两者用共用紧凑确认框，仅提供确认/取消；默认Enter/Esc/关闭为取消，取消按钮与原操作按钮严格对齐。确认才丢弃输入、退出编辑并恢复新增表单，不改变已保存数据。
- 保存已有词的草稿时，按词名、主词释义、关联词及重点，与载入基线和最新数据做三方合并：未改部分采用最新值，同一部分发生不同修改则拒绝覆盖并保留草稿。普通记忆状态及排序不被旧草稿覆盖。
- 保存统一清理字符串首尾空白，保留内部空格、换行和顺序。主词必须有名称与完整释义，关联词同样校验；全空额外项可忽略，不完整项阻止保存。
- 主词以strip().casefold()判重，保留显示大小写；关联词同名允许，不自动建立全局或双向关系。新词默认重点、待记，保存后重置草稿、聚焦主词。
- 新增关联词插在焦点所属词之后（主词之后为第一个位置），删除只作用于聚焦关联词并保留非空确认，删除后聚焦补位项或上一词。两个底部按钮只在表单拥有焦点时显示，删除按钮还要求目标为关联词。
- 每条释义用加号在本行后插入，用垃圾桶删除本行；仅一条时删除禁用。快捷键按焦点所属释义操作，词名聚焦时新增追加、删除不执行。释义图标不参与Tab顺序。
- 表单可拖动关联词箭头及释义柄，只在所属词组内调整，不重建控件、不丢输入/光标；顺序随词条保存。布局变化同步更新Tab顺序。
- 翻译编辑框按换行/折行自适应，单行最小36像素；列表编辑框最长不超过视口，超长内部滚动；表单翻译随内容增长，由外层表单滚动跟随光标。
- 新获得焦点的可编辑文本/数字框取消自动全选并将光标移到末尾，随后可正常点击定位、选择及Ctrl+A；只读快捷键录制框除外。主窗口按钮聚焦后点击空白或非交互标签，将焦点转给窗口，保留按钮状态、Tab导航及快捷键。
- 词性为n./v./adj./adv./prep./pron./conj./interj./其他。列表双击词性打开独立浮层，按标签中心定位，完整显示9项；点击、数字1～9、n/v/a或Enter立即选择，Esc/外点取消，Tab继续编辑。表单保留组合框；a在形容词/副词间切换。

## 6. 十七天背单词

### 6.1 抽词、阶段与操作快照

- 操作日期/时段使用北京时间UTC+8，15:00起为下午。刷新或重新进入页面重新捕获快照，跨时段/跨日不自动更换；刷新提示为“刷新”。
- 上午仅当最近抽词日期不等于快照日期时抽新词；最多抽“每组单词数×每日新增组数”个待记主词，排除所有已参与过本功能的词，固定分组并使用全局递增组号。默认10词×3组，两项均可配置1～1000。
- 当天已有批次不补抽、不重新分组；抽到0词也保存最近日期，下午不抽。抽词、最近日期和组号高水位同事务；系统日期回拨仍按“不等于”处理。
- 阶段为1、2、4、7、15，stage=0表示周期结束并保留参与记录。阶段1直接进入任务，其余按距上次整轮完成日期至少1、2、3、8天到期，逾期进度保留。
- 上午完成置上午标记并清除下午标记；下午若上午未完成，只保存下午标记，若上午已完成则整轮结算：写实际快照日期、清空双时段标记并推进阶段，最终置0。普通已记下状态不受影响。

### 6.2 任务列表、进度与已完成词

- 待完成词按组号、主词ID升序。按钮排列为刷新、日期时段、秒表图标及实时用时、开始/暂停/继续；右侧依次显示“复习：已背/总数”“新词：已背/总数”和已完成显隐按钮。
- 新任务已背数从0起，总数为启动时的剩余主词数；阶段1算新词，其余到期阶段算复习词。已有记录从数据库恢复数量，已背数采用较大、加粗的强调色。
- 回车先揭晓当前词，再按回车记下；鼠标记下使用同一入口。成功后优先选中补位下一词，末项选前一词，全部完成清除选择；失败保留当前词及选择。
- 已完成显隐按钮默认空心圆，显示已完成时圈内显示勾号，提示为“显示已完成”/“隐藏已完成”。显示时将其按组号、ID追加在未完成词下，默认揭晓，无记下按钮且回车不能再次记下；查看它们不启动/继续计时。
- 已完成词依据现有时段标记和当日整轮完成日期查询，stage=1及当日刚推进至2归新词，其他归复习词。不新增词级历史，沿用现有进度的简化判断。
- 学习页允许共用的就地编辑、复制及关联词/释义排序，不提供普通记忆标记、整组编辑、删除或主词排序。

### 6.3 用时与任务记录

- 每个日期、时段最多一条任务汇总。点击开始、单独揭晓待完成词或记下首词可启动；仅进入、刷新、全局显隐及空任务不建记录。
- 运行/暂停只保存在内存，持久化任务状态只有0未完成、1已完成。重启或导入后，未完成任务以暂停状态载入，继续复用原记录。
- 单调时钟测量有效时间，四舍五入为整数秒（0.5进1），暂停后以保存的整数秒续计。开始/继续、手动/空闲/关闭/休眠/更换快照暂停时保存；最后一词完成属于自动暂停，与完成状态、结束时间同事务结算。
- 普通记下仅事务更新学习进度和数量，不写用时；导出使用已保存用时。保存采用累计值，不重复累加；失败冻结内存秒数供重试，异常终止可能丢失最后一次生命周期保存后的时长。
- 切标签、失焦、最小化继续计时。整个应用的点击、滚轮、键盘/输入法及原生快捷键操作重置60秒空闲，鼠标移动不算；超时暂停并累计至边界。恢复/唤醒不自动继续，待完成词的揭晓/记下可继续。
- 只有最后一次有效记下才置完成、记录实际结束时间；此前结束时间必须为空。删除最后待背词只暂停，不判完成。重复记下不重复计数，数据库失败回滚进度和记录。
- 删除词条只扣当前快照任务的对应总数，已背时也扣已背数；当日结算至stage=2仍归新词，计数限制在合法范围。其他历史不动，内部导入替换的删除重建不扣。无词级历史会使跨日遗留标记的扣减有误差。

### 6.4 历史区域

- 学习页下方为独立“背单词记录”面板，默认收起，本次运行内记住展开状态；高度最多半个客户区，表内滚动，普通页草稿状态不受影响。
- 日期倒序，同日上午/下午成组、下午在上。缺失时段只补显不落库，从最早记录补到今天；无记录只显示今天，15:00前不显示今天下午。
- 列为日期、时段、开始时间、结束时间、有效用时、复习词、新词、状态。数量显示已背/总数，所有记录字段读取数据库快照，不实时叠加内存用时；顶部秒表旁的用时独立实时更新。
- 共用用时格式：不足60秒“x s”，不足3600秒“x min y s”，一小时起“x h y min”、不显示秒。起止时间显示HH:MM，跨日保留MM-DD前缀，空值为破折号，悬浮保留完整含秒时间。
- 状态仅显示图标：补显缺失为灰叉，完成为绿勾，历史未完成为柔红叉，当前未完成为金色双三角快进。当前按锁定快照识别，暂停仍属当前任务；完成状态优先。悬浮及无障碍文本说明四态。

## 7. 设置与快捷键

| 操作 | 默认组合 |
| --- | --- |
| 新增关联词 / 删除关联词 | Ctrl+N / Ctrl+M |
| 新增释义 / 删除释义 | Ctrl+J / Ctrl+K |
| 保存单词 | Ctrl+Enter |
| 设置单词重点 | Ctrl+I |
| 显示/隐藏所有释义 | Ctrl+E |

- Alt+1～4或Ctrl+1～4固定切换四页，优先于旧冲突配置，不允许新配置给表单操作；学习页禁用表单操作快捷键，保存只提交列表编辑。
- 业务快捷键须含Ctrl或Alt，拒绝重复、文本/导航保留键及Alt+F4。先数据库提交，再读取配置并替换运行绑定；失败恢复原值，启动仅补缺失设置且避开旧键冲突。
- Qt与Windows原生分发共用动作映射，原生仅在本窗口激活、无模态/下拉弹层且未暂停时接收，兼容中文输入法；失活释放，不影响其他应用，同次按键只执行一次。
- 快捷键修改即时保存，录制可Esc取消；恢复默认仅作用于快捷键。弹窗不自动聚焦首项，点击空白移除输入焦点、结束未确认录制，不显示重复说明/成功提示。
- 每日新增组数、每组词数在“完成”时一起保存，失败保留输入；Esc/关闭不保存本次学习设置。两项以紧凑居中数字框显示在“每日新背…组，每组…个新单词”一行，只影响之后的抽词。
- 按钮提示使用当前实际快捷键，输入保护期间暂停业务快捷键。常规成功操作不显示状态栏；校验错误使用紧凑非模态浮动提示，重复词可定位已有词。

## 8. 数据结构与一致性

### 8.1 当前版本与存储

| 类型 | 当前版本 |
| --- | --- |
| SQLite | 7（由migration.SCHEMA_VERSION定义） |
| 普通词条JSON | 2（transfer.VERSION） |
| 学习进度JSON | 5（study_transfer.VERSION） |

默认数据目录为%LOCALAPPDATA%\\kkMemorizeVocabulary，数据库为vocabulary.sqlite3，日志同目录。--data-dir可指定隔离目录。退出后复制数据目录可完整备份；更新/卸载保留个人数据。

### 8.2 表与约束

| 表 | 字段及用途 |
| --- | --- |
| words | id、text、normalized_text唯一、important、learned、sort_order正整数、created_at、updated_at；分类/排序号/ID索引 |
| related_words | id、级联word_id、text、position |
| senses | id、word_id或related_id二选一、pos、translation、position |
| settings | key/value；快捷键、本机抽词偏好、最近抽词日期及组号高水位 |
| memorize_vocabulary_17day | word_id级联主键、group_number、stage、morning_done、afternoon_done、last_completed_on；阶段/最后日期索引 |
| study_task_history | id、task_date、afternoon、started_at、ended_at、duration_seconds、status、new_total、review_total、new_done、review_done |

- 学习阶段仅为0/1/2/4/7/15；阶段1最后完成日期为空，其余非空；双时段不能同时为1，stage=0清空双标记。
- 学习设置键为study17.words_per_group、study17.groups_per_day、study_last_add_new_vocabulary（YYYY-MM-DD）及study17.group_counter；删除词条不回收组号。
- 任务日期/时段唯一，afternoon为0上午/1下午，status为0未完成/1完成；数量、整数秒非负，已背数不超过总数。未完成结束时间为空，完成必有结束时间。
- 任务起止时间为带+08:00、精确到秒的北京时间文本，任务日期来自锁定快照，允许起止跨日；有效用时不由时间差计算。任务汇总无词条外键或词级明细。

### 8.3 迁移与事务

- 按001～007包内UTF-8 SQL脚本顺序升级，每步BEGIN IMMEDIATE持锁后重读版本，成功提交user_version；失败只回滚当前步骤，重启续迁，拒绝更高版本。失败关闭连接，禁止进入业务读取。
- 历史步骤依次处理基础词条、分类排序、学习表、最近抽词日期、六字段学习模型、任务历史、整数秒。v6→v7将毫秒四舍五入为秒，保留其他数据；旧库不补造不存在的任务历史。
- 新增迁移只追加脚本，不修改已发布脚本。以sqlite3.complete_statement分句执行，不用会隐式提交的executescript；SQL脚本随包交付并验证一致。
- 所有数据值参数绑定，聚合保存、删除、排序及学习更新使用事务。UI仅在成功后更新；词条导入删除重建时同步迁移旧学习进度到新ID。

### 8.4 JSON交换

- 两种文件只接受各自当前实现的最新版本，拒绝旧版/未知新版；完整校验格式、字段、类型及内容后才处理草稿或写库，UTF-8文件使用临时文件原子替换。
- 词条文件格式为kkMemorizeVocabulary，包含words；每词包含text、important、learned、senses、related及可选sort_order。释义/关联词数组顺序及正文保留，不交换本机ID或时间戳。
- 学习文件格式为kkMemorizeVocabulary.study17，包含words、study_records、study_settings、task_history。进度以strip().casefold()词名绑定，词条与进度一一对应；历史包含全量汇总及原ID，校验ID/日期时段唯一、状态/结束时间与数量关系。
- 学习导出在同一读快照获取全部参与词（含未来到期和周期结束词）、进度、最近抽词日期、组号高水位及历史，不写入运行中用时。本机抽词偏好不参与交换。

### 8.5 导入流程

- 普通页导出当前分类/搜索的全部主词（含视口外），可识别词条或学习文件；学习页只接受学习文件。无效结构/内容/编码/版本在普通入口统一提示“数据结构不合法，导入失败”，实际读写错误保留原因。
- 合法学习文件先提供“导入单词和进度”“仅导入单词”“取消”，已有进度或任务历史时明确整体覆盖；取消不改数据/草稿、不切页、不抽词，不重复打开文件选择器。
- 词条先导入非重复项，再逐条/批量比较重复主词。清理首尾空白后，拼写、顺序化释义/关联词、重点和记忆状态全相同则跳过；比较区分大小写，不考虑ID、排序号或时间戳。
- 排序号全有时稳定升序，否则按文件顺序；导入新增词追加到目标分类，主词仅按规范化名称判重。对比卡片左侧保留本机，右侧即时删除重建新ID；同名卡片同步最新内容，批量右侧采用在一个事务按候选顺序执行，最后采用者生效。关闭保留已处理项及未处理的本机词。
- 全量恢复前暂停旧任务。词条阶段之后，独立事务整体替换学习进度、任务历史及相关学习设置；失败一并回滚此阶段，已导入词条保留并说明。仅导入单词不替换进度/历史。
- 恢复成功清除旧计时内存，按当前日期/时段读取任务但不抽词，未完成记录以暂停载入；仅词条刷新原快照，不额外推进学习。
- 文件/数据库耗时处理在后台独立连接执行，半透明全窗口遮罩阻止输入、重复触发及关闭，主线程维持绘制；文件选择、确认及对比阶段可交互。任务结束/失败移除遮罩，后台不访问Qt控件。

## 9. 模块边界与内部接口

- `domain`：WordEntry、RelatedWord、Sense、词性和默认快捷键定义，输入校验。
- `storage`：数据库初始化与迁移、读取聚合、保存聚合、删除、状态变更、两个分类的最大排序号、拖拽及随机排序、快捷键读取与写入；负责事务与 SQL。排序统一通过 batch_update_sort_orders 批量更新，事务提交后发布最大值。
- `transfer`：JSON 文件格式、严格校验、完整词条序列化及原子文件写入；`import_dialog`：重复词左右对比、逐条或批量选择及事务覆盖。
- `busy_overlay`：全窗口半透明遮罩、旋转指示、输入保护及后台任务等待，只在界面线程绘制/处理控件；`transfer_jobs`：后台任务独立Repository连接的生命周期及排序高水位同步，返回普通数据对象，不访问Qt控件。
- `shortcuts`：规范化与校验、按作用域分发、设置生效和失败恢复；`native_shortcuts`：仅在 Windows 主窗口激活期间接收原生组合键，避开中文输入法拦截并在离开窗口或暂停时释放。
- `widgets`：词性选择框、释义输入行、主词/关联词输入组、确认窗口、图标绘制。
- `table`：视图行投影、自定义绘制、行高与换行、遮罩、点击/双击分发、就地编辑。
- `table_style`：仅负责统一列表底色、选中底色、分隔线和译文侧分组竖线；接受现有Qt表格投影与绘制矩形，不维护业务状态或处理事件，不依赖`table`及页面/存储模块。
- `review_navigation`：共用方向键解析、受列表面板范围约束的键盘事件路由；将功能按钮上的导航交给当前WordTable.navigate_entries，不维护选择或业务状态。
- `input_focus`：主窗口及所属对话框的输入焦点策略，新聚焦输入定位末尾，主窗口按钮在空白点击后释放焦点；不处理词条、保存、选择导航或快捷键业务。
- `pos_picker`：词性浮层的完整选项、屏幕内定位、选择/取消信号及共用词性按键解析；不调用窗口或数据库，列表编辑代理负责提交，底部PosCombo复用按键解析。
- `draft_reset_dialog`：清空/取消编辑共用的模态确认、默认取消及原按钮位置对齐；不修改表单或数据库，由窗口在确认后重置输入。
- `drag_reorder`：主词及关联词拖动共用的插入位置计算、动画时长、预览边框和边缘滚动规则，不依赖业务窗口或存储。
- `form_reorder`：关联词输入组及词内释义行共用的拖动事件、快照预览和范围保护，不重建输入控件、不读写数据库；窗口编排blocks排序，WordBlock处理释义行排序并通知更新Tab顺序，拖动期间暂停业务快捷键，结束恢复原暂停状态。
- `window`：筛选及各页滚动记忆、表单编辑状态、焦点目标、设置窗口与提示。
- `learning`：北京时间操作快照、学习任务/历史数据对象及阶段间隔计算；`study_page`：独立学习表格、刷新、计时按钮与上下午先后顺序操作；`storage` 提供生成、查询、完成学习任务及历史汇总的事务接口。
- `study_timer`：单调时钟累计、应用空闲及Windows电源事件、内存运行/暂停状态，持久化通过Repository；`study_history`：只读历史表格、缺失时段投影、日期分组及独立折叠面板，不拼接SQL、不生成任务。
- `migration`：按版本读取UTF-8 SQL包资源，逐步事务执行并提交版本号；`migrations/`：历史建表与数据升级SQL。`storage`连接后调用此入口，升级失败关闭连接，成功后才读取业务状态。新增版本追加脚本并登记，不回改已发布脚本。
- `study_transfer`：独立学习进度JSON的词名绑定快照及带ID的任务历史、完整文件校验与UTF-8原子文件保存；`storage`提供一致性导出快照及全量进度恢复事务，`window`复用词条重复选择界面协调两个导入阶段。
- `app`：命令行入口、用户数据目录、日志、主题、程序生命周期。

数据通过 Python 数据对象在层间传递，UI 不拼接 SQL；所有数据值使用 SQL 参数绑定。没有对外网络 API。

## 11. 验收标准

- 词条聚合、多释义/关联词、唯一校验、级联删除、保存/导入/排序失败回滚及重启恢复。
- 四页鼠标/键盘、遮罩显隐、复制/编辑、Tab/F2导航、输入法、拖动/取消/滚动、独立草稿合并及确认保护。
- 快捷键提交先于生效、冲突拒绝、失败回退、改键重启保留及原生路径去重。
- 抽词固定批次/零词、时段边界/快照、逾期/阶段结束、分类计数、已完成词展示与重复记下保护。
- 整数秒取整、暂停/继续/空闲/关闭/休眠、用时写入频率、历史静态与顶部实时分离、四态图标及缺失补显。
- 各版本迁移、迁移断点/失败、JSON最新版本及完整校验、词条与进度覆盖/取消/仅词条、历史往返及事务失败。
- 默认/最小窗口、125%和150%缩放不重叠；EXE离线无控制台启动，隔离首次保存/重启、更新/卸载保留数据。
- 成品模块和SQL资源与源码一致，不混入外来ICU/API-set DLL。测试数据库与个人数据分离。

具体测试数量、截图及成品验证结果只记录在[验收记录](验收记录.md)，历史条目不覆盖当前规范。
