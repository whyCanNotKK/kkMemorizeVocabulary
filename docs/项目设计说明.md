# 项目设计说明

状态：当前实现规范 · 整理日期：2026-11-23

本文集中描述现行规则。开发操作见[开发指南](开发指南.md)，历史验证证据见[验收记录](验收记录.md)。

## 1. 目标与约束

kkMemorizeVocabulary 是本地离线单词本，提供词条整理、遮罩复习、十七天学习日程及任务历史。Windows 10/11 x64 为完整支持平台；macOS Apple Silicon 提供源码运行与未签名、未公证的 `.app` 试用分发支持。

- 单词、音标、词性、释义由使用者自行输入或导入，不内置词库，不提供联网词典、自动翻译、账号同步或发音。
- 数据保存在本机；普通记忆状态与十七天学习进度独立。
- 开发、测试和演示使用隔离数据目录，不写个人默认数据库。

## 3. 领域概念

| 概念 | 含义 |
| --- | --- |
| 主词 | 拥有独立ID、词名、可选音标、释义、关联词、重点、普通记忆状态及分类排序号的词条 |
| 释义 | 分开的词性与翻译；每个词至少一条已选词性的释义，译文可为空，保留多行正文及顺序 |
| 关联词 | 隶属于主词，可有音标及多条释义；不独立参与主词计数、抽词或记忆标记 |
| 重点 | 主词的星标，不决定学习阶段 |
| 已记下 | 普通列表分类标记，可恢复待记；不等同于十七天周期完成 |
| 学习轮次 | 一个阶段的上午、下午操作；整轮结算后推进阶段 |
| 任务记录 | 一个日期、时段的学习数量与用时汇总，不保存词级历史明细 |

## 4. 列表与编辑

### 4.1 布局、筛选与滚动

- 主界面采用铺满客户区的上下分区布局：取消窗口外围留白及面板外框/圆角，列表与添加/编辑区、背单词记录区使用统一底色；上下区域之间保留8像素深色间隔带，下方区域顶部另有1像素细线，避免内容连接过紧。列表和历史表格横向铺满区域，工具栏、下方标题及表单保留12像素左右内边距，保留必要的纵向内容间距及原有折叠行为。本项仅调整布局和外观，沿用SQLite 10、普通JSON 3及学习JSON 8，无需数据迁移。
- 四个标签为待记、全部、已记、十七天背单词，默认进入待记。“已记”为原“已记下”标签的简称，普通记忆状态及持久化字段不变。普通页按分类、sort_order、ID升序，全部页先待记后已记；学习页按第6节排列。
- 待记、全部、已记采用数据库分页，每页固定500个主词，主词的全部释义及关联词不拆页；页码仅表示当前顺序位置，不是固定分组。数据库先筛选、排序再分页，仅批量装配当前页完整词条，禁止先读取整库聚合再截取。数量、锚点排名及必要排序元数据允许全范围计算，不读取不可见分页完整内容。十七天背单词拥有独立任务内容缓存，不分页。
- 列表底部、添加/编辑区上方固定显示首页、上一页、页码输入、下一页、末页及总数/当前范围，只有一页也保留；空结果只显示共0个主词，不显示第1/0页。输入/粘贴只保留0–9；Enter提交时0改为1，超过上限改为末页，空输入恢复实际页码；Esc/失焦恢复实际页码而不跳转。主动翻页从顶部选首词并聚焦列表，不额外揭晓；同页不重新读取。无新增翻页快捷键，PageUp/PageDown保留页内滚动。
- 普通三分类各缓存当前普通分页最多500词，另共用一份最多500词的搜索分页缓存，学习页独立缓存所需任务内容。普通分页被替换后丢弃其逐词显隐，不累计历史页；切分类缓存有效则直接恢复，相关数据变化后按需更新或使其失效，下次激活仅查询目标分页。所有分页、缓存和视图状态只在本次运行内保存。缓存版本仅随词条内容/分类/排序成功变化，学习计时、学习进度和快捷键写入不使普通缓存失效；非活动缓存的关联词/释义单元格位置用排列索引映射，不按文本匹配。
- 搜索只出现在普通页，覆盖当前分类全部主词，查询strip().casefold()，匹配主词/关联词拼写及其所有释义译文。按主词拼写、关联词拼写、主词译文、关联词译文四档优先，取最高档中各独立文本最早命中位置，再按原分类、sort_order、ID稳定排序；不拼接文本、不提高完全匹配优先级。数据库完成全部匹配排名后仅返回当前结果分页，精确保持Python casefold语义；不新增搜索存储或依赖，沿用SQLite 10、普通JSON 3、学习JSON 8。
- 搜索输入停顿250毫秒后后台查询，清空立即处理；搜索框数量显示整个分类的总命中主词数，不受500词限制。加载时局部提示并暂停旧列表及分页操作，搜索框继续输入，不使用全窗口遮罩。只有最新请求及数据修订号有效时提交；关键词、分类、分页、数量和内容原子更新。数据库读取异常静默保留上次成功快照，不弹错误/重试提示；输入可保留新关键词，旧列表恢复操作，其编辑、分页及导出始终绑定已成功显示的条件。搜索框回车重新请求最新输入；0命中是成功的空结果，不是异常。保存期间需要接管防抖中的搜索时，停止旧定时器并保留唯一新请求；行内提交后先合并已提交变更再继续切分类/翻页，不让延迟回调取消后续动作。
- 查询变化时跟随当前仍命中的选中词及单元格，必要时进入其结果分页；失去匹配即取消定位并到第1页，不跨查询恢复失效选择，输入焦点不变。共享查询成功改变后，其他分类旧搜索位置清除，普通缓存不受影响。清空时有有效搜索选择则只传递选择到普通列表所在页，不传显隐；无选择恢复搜索前页码和滚动，不恢复已失效选择；原页消失退到末页。其他刷新保留有效位置。
- 主词及其关联词整组连续选中，单元格仍可单独定位编辑。词性、翻译横向对齐，关联词仅缩进词名；统一底色和译文侧竖线，不添加关联词外框或词带。
- 主词和关联词均可保存空音标。列表不增设音标列；音标显示以整个主词组为单位：鼠标悬停或当前键盘定位在主词、任一关联词或该组任一释义行时，该组所有已显示词名行的音标一起在单词列右端弱化显示。悬停与定位位于不同主词组时，两组同时显示；移出悬停后仍保留当前定位组。空音标保持空白，不改变答案显隐或展开隐藏关联词；词名优先占用宽度，音标仅使用剩余空间，互不覆盖。此项不改变数据库或交换格式。
- 表头允许拖动单词列、翻译列的右边界，学习页还可拖动周期列的右边界。收藏（组）/单词、词性/翻译之间锁定。拖动翻译右边界时保持周期列宽度，拖动周期右边界时优先调整周期和操作列，周期缩至标题所需宽度后可继续缩翻译列。拖动限制在当前列表视口内，单词至少34像素、翻译至少80像素，操作列至少保持该页默认宽度（待记/已记188、全部154、学习88像素）。
- 可拖动的表头边界常显半透明双竖杠（每杠1像素宽、14像素高，居中），随列宽移动；锁定边界不画调整标记。
- 左键双击可调分隔线，将对应列尽量恢复到当前窗口的默认宽度：单词列206像素，翻译右边界恢复操作列默认宽度，周期右边界恢复周期列默认宽度。固定宽度的词性列随单词边界平移。空间不足时使用距离默认宽度最近的合法值，腾出空间后可再次双击完全恢复；锁定边界、标题文字、空白及右键双击不执行复位。
- 列宽只保存在本次运行内，刷新/切页保留实际宽度，关闭重开恢复默认，不写数据库或配置。窗口变窄时先缩翻译到80像素，再收回操作列超出默认值的空白，再缩周期列至最小宽度，最后缩单词列；再次放大只给翻译增加空间，不恢复此前被压缩的手动宽度。宽度变化重新计算换行行高并保留选择与滚动；测量复用单个临时文本布局文档及本分页有界高度缓存，绘制按需缓存可见文本，不为每行反复创建文档；单元格提交失败时不开始拖动或双击复位。
- 单词列按当前可用宽度优先展示完整词名：词名本身放不下时仅省略词名、不显示音标，悬停词名单元格提示完整词名；有音标时追加4个空格和完整音标。词名完整但放不下全部音标时，保留完整词名、在剩余空间省略音标，剩余空间不足省略号宽度则不画音标，悬停补充完整音标；两者均完整时仅显示第4.2节的操作提示。音标仍只在悬停/键盘定位组显示。主词与关联词、隐藏答案均共用规则，重复释义空白词名单元格不提示。绘制和悬停按实时字体及列宽计算，拖动列宽或窗口收缩后立即更新；提示框按内容自然尺寸显示，保留4个空格，过长时仅受屏幕宽度限制换行，不省略内容。沿用现有数据库及交换版本。
- 四页分别记住滚动位置、当前词/单元格及整组选中状态，均只在本次运行内保留。刷新和显隐恢复视图，不因旧选择强行滚动。鼠标点击标签或Alt+1～4成功切页后，将键盘焦点移入目标页单词列表，恢复该页仍有效的单词定位并将整组最小滚动至可见；无有效选中词时选择当前视口首个主词，空列表仅获得焦点。对当前页再次点击标签或按对应快捷键同样进入列表；提交或页面载入失败时保留原页及编辑焦点。标签按钮的当前页样式与键盘焦点区分，鼠标或快捷键切页后空格不触发旧标签按钮。此项沿用SQLite及交换版本，不持久化视图状态。
- 新增词保存后进入所在分页、默认揭晓、选中并最小滚动至可见；在已记页新增时转到待记页。普通记忆状态切换后追加到目标分类末尾。通过记忆标记按钮或F4切换成功后，按操作前当前列表（含全部页及搜索结果）的主词顺序选中原本的下一词，并将整组最小滚动至可见、聚焦列表；分页边界不视为结果末项，页尾词移出后选原下一分页补入的词；整个分类/搜索结果原本已是末项才选前一词，没有其他词且原词仍在列表时保留该词，列表清空时只聚焦列表。不因排序变化而选中更新后的相邻词，不改变目标词的答案显隐；提交或保存失败时保留原定位及输入。沿用SQLite 10、普通JSON 3及学习JSON 8，无需迁移。
- 揭晓单词时按主词、全部释义和关联词的整组范围做最小滚动：已完整可见则不动，组尾越界仅下滚必要距离，组首在上方则回到顶部；整组超过视口时对齐组首。只滚动列表，不调整窗口。

### 修改后的统一同步

- 保留三个普通分类、唯一搜索和学习页的有界缓存。所有词条写入成功后提交统一变更描述，由集中同步模块决定内容补丁、缓存失效和位置映射；操作入口仅提供已提交变更与定位意图。事务失败不发布变更，界面内容代次及时阻止旧查询提交，编辑器关闭后再安全绘制。
- 拼写、译文及词内增删更新普通缓存并使搜索失效；音标、词性、重点和词内纯排序仅局部更新。新增、删除、分类变化使成员或顺序受影响的分页失效，跨页分类数量也必须同步；非活动页不主动查询。批量导入和清空统一失效，后台连接传递提交摘要，后续失败不遗漏此前已提交的变化。学习计时、任务完成及设置不使普通词条缓存失效。
- 关联词/释义位置使用操作提供的旧到新映射，覆盖当前页、非活动缓存、搜索位置和学习页；不按文本匹配。表单通过原控件身份追踪位置。目标已删除或整词替换无法可靠对应时，回到同一主词词名，保留显隐、不自动编辑；失效的延迟编辑取消。主词移除仍沿用原下一词/上一词及分页补位规则。
- 查询结果的条件、内容、数量、页码原子提交；失败静默保留最后成功快照，同时恢复实际页码输入及导航状态。已成功写入不因后续读取失败回滚，失效快照不得作为有效缓存复用。
- 本次仅调整运行内同步与视图状态，沿用SQLite 10、普通JSON 3、学习JSON 8，无需迁移。

### 4.2 显隐、复制与鼠标操作

- 启动默认隐藏答案，隐藏组只显示主词和灰色遮罩。遮罩左右范围保持原尺寸，点击范围垂直覆盖单元格整行；左/右键均揭晓整组、选中主词并聚焦列表，中键及左右空白不揭晓。
- 释义通过任一入口揭晓后，隐藏遮罩原有的悬浮提示自动关闭，无需移动鼠标；普通页和学习页统一处理。列表刷新、切页等投影重建时同样清除旧提示，避免提示与当前内容不一致。此项仅调整提示生命周期，不改变数据库或交换版本。
- 鼠标悬浮提示默认最长显示5秒，从提示实际出现时开始计时；鼠标移开、内容变化或其他原有关闭操作仍可提前消除，鼠标静止且没有提前关闭时到期自动消失。自动合并按钮的规则提示为唯一例外：停留期间不设显示时限，宽度按最长说明的实际文字宽度（含缩进及边距）展开，屏幕可用宽度不足时才换行，浮层始终留在屏幕内；移开鼠标、点击按钮、窗口失活或关闭时隐藏。其他列表、表头、表单及设置提示沿用5秒规则，不改变数据库或交换版本。
- 普通列表单独揭晓/隐藏通过共用入口处理，Ctrl+左键已显示翻译和空格可隐藏整组。每分类当前缓存页独立保存逐词显隐，其他分类不联动；同页刷新保留交集词显隐，新补入词按眼睛标记初始化，换分页按该分类眼睛标记重新初始化。
- 四个标签各有独立eye_visible标记，启动均为false；false显示闭眼且新普通分页默认隐藏，true显示睁眼且默认显示。眼睛及默认Ctrl+S反转标记并统一当前列表显隐。用户单独显隐后非空列表全显则设true、全隐设false、混合保留原值；这是赋值，不再次触发批量操作。加载、补位、删除、任务完成等非显隐事件及空列表不自动改变标记。普通显隐只改缓存及投影，不读词条列表；学习单独揭晓涉及计时的业务写入照旧。
- 搜索结果始终显示所有释义/关联词，隐藏眼睛控件，禁用包括Ctrl+S、空格、Ctrl+译文点击在内的一切隐藏入口，移除译文提示中的隐藏释义行，复制/编辑提示保留。搜索不读写普通眼睛标记或逐词显隐，搜索内容缓存与普通缓存隔离；仅实际内容修改同步各缓存。搜索框空格仍用于输入。
- 单词名称所在单元格整格（包括空白、音标及关联词箭头）支持单击复制完整词名、双击/右键编辑。后续释义行的空白词名格只支持右键整词复制。单击仍延迟系统双击间隔，双击取消复制；按住拖动不复制，关联词箭头保留左键拖动排序，右键仅整词复制该关联词的拼写、音标及所有释义，不进入编辑。已显示翻译仅实际文字单击复制完整正文（含换行），词性单击只选中。
- 词名可在隐藏时编辑，词性和翻译须先揭晓。右键或双击进入编辑；列表及其编辑框禁用Qt默认右键菜单，键盘剪贴板操作保留。
- 列表操作提示使用现有鼠标左右键图标，与文字垂直居中。隐藏遮罩为「查看释义和关联词 · [鼠标左键图标] · [鼠标右键图标] · 空格」，学习页末尾改为「输入词性」。主词和关联词词名显示两行「复制单词拼写 · [鼠标左键图标]」「编辑拼写和音标 · [鼠标右键图标]」；截断时仍按第4.1节在操作提示之前补充完整内容，拼写隐藏时不得泄露答案。已显示译文文字显示三行「复制 · [鼠标左键图标]」「编辑 · [鼠标右键图标] · F2」「隐藏释义 · Ctrl + [鼠标左键图标] · 空格」；翻译单元格内文字外的空白及空译文显示后两行，不提示复制。已显示词性显示两行「按住拖动改变释义排序」「编辑 · [鼠标右键图标]」。关联词折角箭头显示两行「按住拖动改变关联词排序」「整词复制 · [鼠标右键图标]」；主词拖动柄为「按住拖动改变单词排序」。普通页星标首行显示「取消重点 · F1 · [快捷键]／设置为重点 · F1 · [快捷键]」（[快捷键]替换为当前实际重点组合，改键即时更新），第二行显示「整词复制 · [鼠标右键图标]」。编辑图标在「编辑单词」后追加当前实际快捷键（默认Ctrl+E，改键后即时更新）。空白词名格及学习组号不增加上述提示。本项不改变交互、数据库或交换版本。
- 待记／已记页的主词操作顺序为拖动、整词复制、编辑、记忆标记、删除。全部页从整词复制开始，后续顺序相同。学习页整词复制在首位，待完成词的记下按钮在其后。普通页编辑提示为「编辑单词 · 当前实际快捷键」，记忆标记按当前状态提示「标记为"记下" · F4」或「标记为"待记" · F4」。
- 右键点击星标／组号列、后续释义行的空白词名单元格或操作列空白处，复制所在行的主词或关联词。操作图标仍只响应左键。整词复制取得所选词的拼写、音标及有序释义，保持遮罩和编辑状态。成功提示「已复制：xxx的拼写、音标和所有释义」。已有词校验失败按缺少字段提示「整词复制失败：单词拼写不能为空」或「整词复制失败：释义词性不能为空」，并保留剪贴板。数据和交换版本沿用现有版本。

### 4.3 编辑与键盘导航

- 四个列表共用就地编辑。Enter（含数字键盘）保存并关闭编辑器，不继续触发列表记下；Shift+Enter在翻译内换行，Esc取消。失焦或保存快捷键同样提交。
- 编辑词名时，在词名编辑框下方悬浮音标框，主词/关联词及隐藏答案状态均支持；两个框之间切换焦点不提交，Tab从词名进入音标，Shift+Tab返回，音标Tab继续到下一字段。Enter、外部失焦或保存快捷键将词名和音标一起事务保存；Esc同时取消。失败保留两框输入并阻止后续操作。弹层保持在列表视口内，底部空间不足时移到词名框上方，不改变行高或数据库结构。
- 四页列表共用运行内鼠标定位标记：真实鼠标移动后置为true；非悬停引起的当前单元格/选择变化、键盘导航、回车跳过、焦点转移、切页及列表重建后置为false，静止鼠标及悬浮提示本身不重新启用。标记为true且鼠标位于列表可编辑单元格时，F2直接编辑鼠标所指字段，允许跨主词组：单词列首条词名格（隐藏答案时也可编辑）进入拼写/音标编辑，进入、取消及保存均与右键词名编辑一致，保留原有释义显隐，不自动揭晓或隐藏，已显示词性列进入词性选择，已显示翻译列（含空白和空译文）进入译文编辑。重复释义空白词名格、隐藏遮罩、星标/组号/周期/操作列及列表外不作为鼠标编辑目标；没有可用鼠标目标时，F2仅在当前主词组已选中且释义显示时编辑主词第一条翻译。列表正在编辑时（含拼写、音标、译文及词性选择浮层），F2先按现有规则立即提交当前输入，成功后继续使用相同的鼠标定位或主词首条译文回退逻辑；失败保留原编辑器及输入，不切换。提交前捕获逻辑目标，提交导致释义或关联词删除/重排时映射到原指向内容的新位置，目标已删除或退出搜索结果时不误编辑其他内容。长按F2不重复提交。拖动、其他模态/下拉弹层、忙碌或表单/搜索输入框聚焦期间不接管F2。同一已选词组内的译文悬停定位仅在鼠标定位标记为true时跟随，保留滚动和整组选中；悬停不跨组选词、不抢输入焦点。此项不改变数据库或交换版本。Tab/Shift+Tab按词名→音标→各条词性/翻译→关联词→下一主词顺序连续编辑，词名和音标之间不提交，其余跨字段先保存；跳过操作列及重复空白，首尾不循环。
- 普通三页（包括搜索结果）列表聚焦、未编辑且未拖动时，Del删除当前有效选中行所属的主词整组，即使定位在关联词或后续释义行也删除该主词及全部释义、关联词；隐藏答案时同样可用。复用垃圾桶的草稿保护和事务入口；垃圾桶与Del共用设置中清空内容的紧凑无标题栏确认样式，定位在该主词垃圾桶附近，初始焦点及默认操作为取消。确认文案固定为「同时还会从十七天背单词记录中删除(若存在)，确认移除吗？」，仅提供「确认」「取消」；Tab/Shift+Tab切换按钮，Enter执行当前按钮，初始Enter、Esc及关闭均取消，不删除。无选中词、学习页、输入框、弹层及忙碌状态不触发整词删除；带Ctrl/Alt/Shift等修饰键不触发（数字键盘Del同普通Del）。垃圾桶悬浮提示为「删除单词 · Del」。Del或垃圾桶删除成功后，按操作前当前列表（包括搜索结果）的主词顺序选中原本的下一词，末项选前一词，并将目标整组最小滚动至可见、聚焦列表；删除最后一个词后仅保留列表焦点。取消或删除失败时保留原选择，不移动到其他词。本项沿用SQLite及交换版本，无需数据迁移。
- 默认Ctrl+E将普通页当前选中行所属的主词整组载入下方编辑区，共用编辑图标入口：先提交行内编辑，失败则阻止；已有草稿沿用保存/放弃/取消提醒，编辑同一主词时保留草稿并展开聚焦。选中关联词或释义行也编辑所属主词；没有有效选中词时不执行，在十七天背单词页无效。快捷键可在设置中修改。
- 列表就地编辑通过任一现有方式提交时，清理拼写或译文首尾的空白（含换行）。译文为空且同一个词还有其他释义时，直接删除当前释义；仅剩一条时保留词性并保存空译文。关联词拼写为空时直接删除该关联词及其释义；主词拼写为空且无关联词时直接删除主词及其释义，沿用主词删除的学习记录和任务计数处理。有任何关联词的主词拼写为空时，在当前编辑框上方提示「单词拼写不可为空」。音标为空不触发删除。
- 删除后，Tab/Shift+Tab 跳过已删除的内容，继续到原编辑顺序中最近的可编辑字段。清空拼写删除主词时，若下方正编辑该主词，未修改的表单回到新增状态，有未保存输入则保留为新增草稿。提交失败保留编辑器和输入，阻止切页、刷新、导入导出等后续操作。学习页内容编辑共用主词数据，不抽词、不推进学习进度。
- 词名、音标和翻译编辑框支持用 Ctrl+V 粘贴整词，列表立即预览该词的拼写、音标、所有释义和条数，已有遮罩继续生效。编辑行消失时，将翻译编辑器移到该词最后一行。整词粘贴保留载荷中的空译文；粘贴后再手动清空当前译文时，按列表清空规则处理。跨字段 Tab 按新释义顺序定位并沿用现有提交时机。提交使用原始快照校验目标，失败保留预览和输入。提交前 Esc 关闭编辑器并恢复编辑前的内容、行数和原单元格。普通文本仍按 Qt 粘贴。
- 上下箭头按主词导航，跳过释义及关联词行，首尾停止且不自动翻分页；Tab/Shift+Tab到分页编辑边界不跨页；无选择时选中视口内首个主词且保留滚动位置。列表聚焦且未编辑时，左右箭头不触发导航；普通三页W/A/S/D不触发导航或按字母查找，空格切换当前整组答案。四页列表聚焦、有有效选中词且未编辑/拖动时，普通回车及数字键盘回车复用第6.2节的揭晓并跳过规则：隐藏词先揭晓整组再移到下一主词，隐藏的末词先揭晓停留，再次回车全页隐藏并回到首词；已显示末词直接全页隐藏并回到首词，单词仅一个时同理。普通三页按当前列表（含搜索结果）所有主词循环，不改变普通记忆标记、重点、排序或学习进度；搜索结果在当前分页内回车仅选下一词，末词回到首词，不触发全页隐藏；搜索禁止所有隐藏入口。无选择、空列表、带修饰键或长按回车不跳过。十七天页继续排除当前时段已完成词，并按第6.2节处理词性、拼写、空格。Ctrl+上下箭头只滚动。此项沿用现有数据库及交换版本。
- 列表面板内功能按钮聚焦时也可用上下箭头进入当前列表，W/S不再路由到列表；输入框、编辑、拖动、弹层、忙碌状态不路由这些按键。
- 搜索框按下箭头或无修饰键的回车（含数字键盘回车）均请求第1页并在最新查询成功后聚焦首个结果；250毫秒等待期立即发出且保留进入意图，执行期等待完成，不触发列表回车；新输入、切分类或主动移焦取消旧意图；无结果时同下箭头处理，不修改查询或触发其他操作；非空搜索的首个主词组按上箭头返回搜索框并将光标放末尾。W键及空搜索不触发返回搜索框。
- 普通三页（包括搜索结果）列表聚焦、有有效选中词且未编辑/拖动时，固定快捷键F1及当前配置的重点快捷键（默认Ctrl+I）切换所属主词的重点/非重点，F4切换普通已记下/待记状态；定位在关联词或后续释义行、答案隐藏时同样生效。两者复用鼠标星标、记忆标记入口，即时事务入库并刷新星标及分类，失败保留原状态；不改独立表单草稿。无选中词、输入框、弹层、忙碌及十七天背单词页不触发；固定F1/F4带修饰键不触发，配置的重点组合按实际修饰键匹配。普通页星标首行提示按状态显示「设置为重点 · F1 · [快捷键]」或「取消重点 · F1 · [快捷键]」（[快捷键]替换为当前实际重点组合，改键即时更新），第二行整词复制提示保留；学习页提示及学习记下规则保持不变。沿用SQLite 10、普通JSON 3及学习JSON 8，无需迁移。
- 长按回车、空格、F1、F2、F4、Del及业务快捷键不重复触发；上下方向键允许连续导航。

### 4.4 排序与拖动

- 待记/已记的主词拖动仅在无搜索时可用，全部页及学习页无主词拖动。待记、全部、已记三页均在无搜索时显示星标列表头的随机图标按钮，复用现有样式；悬浮提示分别为“随机排列全部待记单词”“随机排列全部单词”“随机排列全部已记单词”。搜索非空时隐藏按钮，清空恢复；对应整个分类至少有两词时可用，全部页至少其中一个分类有两词时可用，否则禁用；不以当前500词的数量判断，学习页不显示。
- 随机排列使用random.shuffle，待记/已记页仅打乱对应分类；全部页分别打乱待记、已记两类，保持待记在上、已记在下，各分类内重新赋排序号1…N，不足两词的分类不改动。两类的全部变化项通过同一次batch_update_sort_orders事务保存，失败全部回滚；保留词条内容、重点、记忆状态及学习进度，同一分页刷新保留交集词显隐，新成员按眼睛标记初始化。成功后进入当前分类第1页、选首词并滚至顶部，清零该页滚动记忆，其他页滚动记忆保留；失败保留原顺序和滚动位置。此项沿用SQLite 10、普通JSON 3及学习JSON 8，无需数据迁移。
- 按关联词折角箭头拖动，可在同一主词内重排关联词整组；按已显示词性拖动，可在同一主词/关联词内重排释义。学习页同样支持这两种排序。
- 越过系统拖动阈值后才启动，采用150ms让位动画、内容跟随及边缘滚动，不绘制额外预览边框。Esc、失焦、刷新、超出范围或原位松开取消/不写入；隐藏答案或不足两项时不启动。
- 列表拖动前提交当前单元格，失败不启动；独立录入草稿不处理。写入失败恢复原顺序，排序不改变ID、内容、重点、记忆状态或学习进度。
- 分页主词拖动只允许页内，不自动跨页；存储接口使用完整分类位置或稳定邻接ID，避免第2页误写到第1页。三种排序均先事务写入，再用返回变更及排列映射更新当前缓存/词组投影，禁止写后读取列表。必要ID/position/sort_order校验不受此限制；其他受影响分页仅标记失效。词内排序不改变搜索排名，不触发重搜。随机作用整个分类，仅处理ID/排序元数据，提交后读取新第1页最多500词。
- 分类排序号独立递增：新增/转入分类追加到末尾；主词拖动以“前项+1”为目标，仅顺延冲突项至首个无需调整的位置。批量更新共用事务接口，提交后才发布排序高水位。

## 5. 独立录入草稿与输入控件

- 普通页下方为添加/整组编辑区，默认展开，可居中箭头折叠；学习页隐藏该区域但保留草稿、编辑ID及折叠状态。高度随内容增长，最多半个客户区，超出只滚动表单内容，标题/底部按钮固定。
- 搜索、失焦、切页及列表编辑/排序不提示保存或清空草稿。仅关闭、主动清空/取消、载入另一主词、导入或删除正在编辑词等可能丢失/替换草稿的操作处理保护。
- 退出、载入另一主词或导入等需要处理未保存草稿时，共用“是否保留当前输入？”确认框，正文为“单词编辑区域还有未保存内容”；仅提供“保存”“放弃”，初始焦点在对话框，不聚焦任一按钮且无默认操作。右上角关闭或Esc均取消原操作并保留输入，初始Enter不保存或放弃。保存成功或明确放弃才继续原操作，保存失败仍保留草稿并阻止原操作。
- 新增显示“清空”，编辑显示“取消”。两者用共用紧凑确认框，仅提供确认/取消；默认Enter/Esc/关闭为取消，取消按钮与原操作按钮严格对齐。确认才丢弃输入、退出编辑并恢复新增表单，不改变已保存数据。
- 保存已有词的草稿时，以表单中的词名、音标、主词释义、关联词及重点完整覆盖数据库内容；列表修改独立即时入库，不回填或阻止草稿保存。表单保存后刷新列表。普通记忆状态、排序及学习进度保留数据库当前值。

## 6. 十七天背单词

### 6.1 抽词、阶段与操作快照

- 操作日期/时段使用北京时间UTC+8。学习日于每日05:00切换：00:00至04:59:59仍归前一学习日；上午为05:00至14:59，15:00起为下午，下午时段延续至次日04:59。刷新或重新进入页面重新捕获快照，跨时段/跨学习日不自动更换；刷新提示为“刷新”。因此午夜后仍执行前一学习日下午任务，05:00后才进入新学习日并允许生成上午新词任务。
- 每次切入学习页或刷新均检查抽词条件；上午仅在每日新背开关开启且最近抽词日期不等于快照日期时抽新词。最多抽“每组单词数×每日新增组数”个待记主词，排除所有已参与过本功能的词（含stage=0）。先从候选重点词中无放回随机抽取目标数量的80%（向下取整），重点候选不足时全部选入；再从剩余全部候选词（含未抽中的重点词和非重点词）中无放回随机补足目标数量，总候选不足时全部选入。80%是优先配额而非最终重点比例上限。例如目标50个、重点仅35个时，先选35个重点，再补15个。合并后随机打乱，再按现有每组词数固定分组并使用全局递增组号；不改变待记分类、重点标记或既有学习进度。沿用SQLite 10、普通JSON 3及学习JSON 8，无需迁移。默认10词×3组，两项均可配置1～1000。
- 当天已有非空批次不补抽、不重新分组；抽到0词不更新最近日期或组号高水位，开关关闭不执行抽词，下午不抽。非空抽词、最近日期和组号高水位同事务；系统日期回拨仍按“不等于”处理。
- 程序启动时检查是否至少有1个可抽新词，没有则将每日新背开关持久化为关闭；有词时保留原设置，不自动重新开启。旧配置缺少此键时默认开启。新增、导入词条均不自动开启。
- 设置由关闭改为开启时复用同一可抽词检查；无词则保持关闭，在图标上方提示“当前待记单词列表中的词均已背过”。检查通过后，以当前北京时间快照执行正常抽词流程（仍受上午及当天非空批次限制），设置与抽词同事务，失败回滚。关闭仅停止后续抽词，不移除已有任务。开启成功同步学习页、任务计数及历史；当天已有任务记录时将抽到的新词加入总数，已完成记录恢复未完成并清空结束时间，保留已背数量、开始时间及累计用时。
- 阶段为1、2、4、7、15，stage=0表示周期结束并保留参与记录。阶段1直接进入任务，其余按距上次整轮完成日期至少1、2、3、8天到期，逾期进度保留。
- 上午完成置上午标记并清除下午标记；下午若上午未完成，只保存下午标记，若上午已完成则整轮结算：写实际快照日期、清空双时段标记并推进阶段，最终置0。普通已记下状态不受影响。

### 6.2 任务列表、进度与已完成词

- 待完成词按组号、主词ID升序。按钮排列为刷新、日期时段、秒表图标及实时用时、开始/暂停/继续；右侧依次显示“复习：剩余数/总数”“新词：剩余数/总数”和已完成显隐按钮。分子为大数字，分母保留弱化显示；有任务记录时总数读取记录，无记录时总数为对应待完成数。
- 当前锁定时段的任务记录状态为已完成时，隐藏顶部秒表图标、实时用时及开始/暂停/继续按钮，不保留其布局占位；刷新、重进页面或查看已完成词仍保持隐藏。切到未完成或尚无记录的时段时恢复显示。仅无待背词不视为完成，仍沿用原有按钮禁用规则；日期时段、刷新、剩余/总数及历史区域不受影响。不改变任务状态、计时结算或数据版本。
- 学习列表为空时，视口中央显示两行：当前时段任务已完成时，首行为“当前时段任务完成，总时长 x h y m，有效用时 x h y m，效率 z%”，第二行为“在新时段点击[刷新图标]刷新，开启新任务”；无任务或任务未完成时，首行为“当前暂无待背单词”，第二行为“点击[刷新图标]刷新任务”，不将空列表原因归于时段变化，也不承诺刷新后必有新任务。图标沿用左上角刷新按钮的图形和尺寸，图标及其后的蓝色下划线“刷新”均可点击，悬停为手形光标，调用同一个刷新入口并重新捕获当前日期/时段；刷新失败保留当前提示。列表非空时隐藏提示，再次为空时根据任务状态恢复。仅空列表不视为任务完成。不改变任务数据、计时规则、数据库或交换版本。
- 两个剩余数按当前时段待完成主词分别计数，采用较大、加粗的强调色；阶段1算新词，其余到期阶段算复习词。刷新、重启、查看已完成及任务完成后保持此含义；历史区域仍显示已背/总数。
- 十七天页仅在列表实际聚焦、有选中词且未编辑/拖动时处理练习输入。隐藏释义时，输入主词任意一条释义的词性键揭晓整组（含关联词）：1/N名词、2/V动词、3/A形容词、4副词、5/P介词、6代词、7/C连词、8/I感叹词、9/E其他。字母不区分大小写，支持数字键盘；仅关联词词性不算命中，本次揭晓键不计入拼写。隐藏时空格、错误词性键及记下按钮左键均无操作；右键记下图标或回车先揭晓当前整组再跳过。鼠标遮罩、Ctrl+点击译文隐藏及全局显隐入口保留，单独揭晓沿用计时启动规则。
- 显示释义后，逐键严格匹配主词拼写（包括大小写、内部空格数量、标点），关联词行也匹配主词。匹配的可见非空格字符临时变黄，空格只推进；最后一个字符匹配后立即记下。进度为零时空格隐藏整组；匹配中输错任意字符只清空进度并恢复原色，错误键不复用、不同时隐藏。Backspace/Esc清空；待完成词按回车（含数字键盘）跳过到下一个待完成主词，不触发记下；释义隐藏时先揭晓当前整组，成功后再移动，揭晓失败则不跳过；若当前词是最后一个待完成词，则本次只揭晓并停留，下一次才回首词。已完成词的回车无操作；带Ctrl/Alt/Meta/Shift修饰或自动重复的回车不跳过。仅接受直接逐键字符及Shift大小写/标点，不接受粘贴、输入法上屏、自动重复；Ctrl/Alt/Meta组合键沿用业务快捷键，不参与匹配。不设输入超时。
- 同一主词组内切换单元格保留进度；切换主词、清除选择、列表失焦、切页、刷新、显隐变化、编辑或拖动时清空。颜色及进度仅在内存中，不改数据、复制内容或原有长词省略。已完成词不参与拼写记下。
- 释义显示后鼠标记下与拼写完成共用入口；入口再次校验待完成词和释义已显示。成功后优先选中补位下一词，末项选前一词，全部完成清除选择；失败保留当前词、选择和释义，清空匹配进度并显示现有错误提示。按钮悬浮提示均为两行：隐藏时第一行为“记下（需先展示释义）”，第二行为“查看释义并跳过 · [鼠标右键图标] · [回车图标]”；显示时第一行“记下 · [鼠标左键图标] · [单词拼写]”，第二行“跳过 · [鼠标右键图标] · [回车图标]”。其中[单词拼写]是固定文字及方括号，其余括号位置绘制已有样式的图标，与该行文字垂直居中。右键点击记下按钮与回车共用跳过入口：隐藏时先通过共用揭晓入口显示当前整组（沿用单独揭晓的计时规则），成功后再移动，但隐藏的最后一个待完成词只揭晓并停留。已显示的末词跳过时，先通过全局显隐入口强制隐藏当前标签页全部词（含当前可见的已完成词），同步学习页全局隐藏状态及右上角眼睛按钮的勾选和状态记录，再聚焦第一个待完成主词；其他词按当前列表顺序聚焦下一个待完成主词，排除追加显示的已完成词；目标沿用原显隐，不执行记下，不改变完成进度、计数或排序；已显示词的跳过不改变计时。切到另一词清空拼写进度，只有一个待完成词时，隐藏状态首次操作揭晓并停留，显示状态再次操作同样执行全页隐藏并聚焦自身；右键点击其他词的记下按钮以被点击词为跳过起点。操作前行内提交失败则不移动。此项沿用数据库及交换版本。
- 学习页翻译列标题为“翻译（输入词性查看释义  1|n：名词，2|v：动词，3|a：形容词，4：副词，5|p：介词，6：代词，7|c：连词，8|i：感叹词，9|e：其他）”，单行展示，宽度不足时省略且仅此时悬停显示全文；能完整显示时不提示。按实时列宽、字体及表头样式判断，不增加表头高度或撑宽列。本交互沿用SQLite 10、普通JSON 3及学习JSON 8，无需迁移。
- 已完成显隐按钮默认空心圆，显示已完成时圈内显示勾号，提示为“显示已完成”/“隐藏已完成”。显示时将其按组号、ID追加在未完成词下，默认揭晓，无记下按钮且回车不能再次记下；查看它们不启动/继续计时。

- 学习页允许共用的就地编辑、复制及关联词/释义排序，不提供普通记忆标记、整组编辑、删除或主词排序。

### 6.3 用时与任务记录

- 每个日期、时段最多一条任务汇总。点击开始、单独揭晓待完成词或记下首词可启动；仅进入、刷新、全局显隐及空任务不建记录。
- 开始/暂停计时图标右侧的“学习间隔”仅在计时运行中隐藏；学习前、暂停及任务完成后均显示。从最近一次已完成任务的实际结束时间算到现在，向下取整到分钟，使用d（天）、h（小时）、m（分钟），省略零值单位，零分钟显示0 m；不显示秒或超过天的单位。没有完成记录或当前时间早于结束时间时显示“学习间隔： —”。进入/刷新页面及从学习中恢复显示时立即更新，页面可见时每70秒自动更新一次，不跟随用时秒表每秒刷新。任务完成后立即改用本次结束时间。沿用 SQLite 10、普通词条 JSON 3、学习进度 JSON 8，无需数据库迁移。
- 运行/暂停只保存在内存，持久化任务状态只有0未完成、1已完成。重启或导入后，未完成任务以暂停状态载入，继续复用原记录。
- 单调时钟测量有效时间，四舍五入为整数秒（0.5进1），暂停后以保存的整数秒续计。开始/继续、手动/空闲/关闭/休眠/更换快照暂停时保存；最后一词完成属于自动暂停，与完成状态、结束时间同事务结算。
- 普通记下仅事务更新学习进度和数量，不写用时；导出使用已保存用时。保存采用累计值，不重复累加；失败冻结内存秒数供重试，异常终止可能丢失最后一次生命周期保存后的时长。
- 切标签、失焦、最小化继续计时。整个应用的点击、滚轮、键盘/输入法及原生快捷键操作重置60秒空闲，鼠标移动不算；超时暂停并累计至边界。恢复/唤醒不自动继续，待完成词的揭晓/记下可继续。
- 只有最后一次有效记下才置完成、记录实际结束时间；此前结束时间必须为空。删除最后待背词只暂停，不判完成。重复记下不重复计数，数据库失败回滚进度和记录。
- 删除词条只扣当前快照任务的对应总数，已背时也扣已背数；当日结算至stage=2仍归新词，计数限制在合法范围。其他历史不动；导入覆盖为原地更新，不删除主词，也不扣任务计数。无词级历史会使跨日遗留标记的扣减有误差。

### 6.4 历史区域

- 学习页下方为独立“背单词记录”面板，每次切入“十七天背单词”页并成功载入当前任务后，若有待完成学习任务则默认收起，没有待完成任务则默认展开（包括任务已全部完成、正在显示已完成词时）。进入后可手动展开或收起，页内刷新、计时、记下及显隐操作保留手动状态；再次切入时重新按任务情况设置。高度最多半个客户区，表内滚动，普通页草稿状态不受影响。沿用当前数据库及交换版本。
- 面板标题栏右上角始终显示“合计 X 个单词，彻底完成 Y 个单词”（收起时也显示），X直接统计memorize_vocabulary_17day全表条数，包含正在学习和stage=0已结束周期的主词；Y统计其中stage=0的条数，即第15阶段上午、下午均完成并已结算结束周期的主词，仍为stage=15或仅完成一个时段的不计入Y。两者均不按当前时段、到期状态、普通记忆分类或历史任务累计数量筛选，不计关联词。两个数字均沿用上方复习/新词剩余数的22像素、700字重，X使用原强调色，Y使用亮青色#4BEDFC；整行悬浮提示“合计包括已经背完的和正在背的；彻底完成指第15阶段上下午均已完成”。进入页面、刷新、抽词、记下、删除/清空及恢复进度后同步。此项仅增加现有字段的派生统计，沿用SQLite 10、普通JSON 3及学习JSON 8，无需数据迁移。
- 日期倒序，同日上午/下午成组、上午在上、下午在下。缺失时段只补显不落库，从最早记录补到当前学习日；无记录只显示当前学习日，当前学习日15:00前不显示下午。当前学习日按第6.1节的北京时间05:00边界计算。
- 同一天的日期列跨上午、下午两行合并，日期在合并单元格内水平、垂直居中；今天仅有上午时保持单行居中。悬浮提示根据该行日期在本地计算并显示“周一”至“周日”。刷新及跨时段后重新按日期合并，分隔线位于整组底部；其他列仍逐时段显示。不改变数据库、交换格式或记录顺序。
- 列为日期、时段、开始时间、结束时间、记忆间隔、总时长、有效用时、效率、复习词、新词、状态。开始/结束时间均只显示时分，不显示日期前缀。次日00:00至04:59的时间在对应时间列右侧固定位置显示白色十字闪亮星标，与时段列的月牙区分，时间文本仍保持原有居中对齐，悬浮图标提示“次日凌晨”；其他时间不显示图标或时间悬浮提示。数量显示“已背 / 总数”，斜杠居中，两侧数字各预留三位宽度，超过三位时在可用空间内对称扩展。历史以数据库快照为准，不实时叠加内存用时；顶部秒表旁的用时独立实时更新。
- 记忆间隔按任务日期及上午、下午顺序查找最近的前一个已完成时段，跳过缺失和未完成时段。用本时段的开始时间减去该时段的结束时间，四舍五入至整小时，显示“x h”。本时段有开始时间即可计算。缺少前一个已完成时段或开始时间早于该时段的结束时间时，显示破折号。历史数据变化时在本地重算并缓存于内存，不改变数据库或交换格式。
- 时段列仅显示居中的彩色图标：上午为金色太阳，下午为淡蓝色月亮；悬浮及无障碍文本分别为“上午”“下午”。沿用同一天合并居中的日期列、日期底色和组末分隔线，仅调整历史视图，不改变数据库及交换格式。
- 共用用时格式：不足60秒“x s”，不足3600秒“x m y s”，一小时起“x h y m”、不显示秒；分钟后的秒数为0时省略“0 s”，小时后的分钟数为0时省略“0 m”。总用时为0仍显示“0 s”。顶部实时计时使用此格式，不改变数据库及交换格式中的整数秒。起止时间显示“HH：MM”，使用略放大的全角冒号，小时和分钟各占等宽的两位数字。跨日保留MM-DD前缀，空值为破折号。
- 完成提示与历史表共用总时长及效率：总时长用结束时间减开始时间，跨日按实际时间差计算，四舍五入到整分钟（30秒进1）。有效用时按已结算的秒数向下取整分钟。历史表两者仍显示“x m”（如1小时40分钟显示100 m）；完成提示两者不足60分钟显示“x m”，达到60分钟显示“x h y m”（如100分钟显示1 h 40 m，60分钟显示1 h 0 m），不显示秒或天，不要求数字对齐。效率以有效用时秒数除以未取整的总时长秒数，四舍五入到整数百分比。未结束或结束早于开始时，总时长和效率均显示破折号；起止相同则总时长为“0 m”，效率显示破折号。派生数值随历史快照缓存于内存，沿用SQLite 10、普通JSON 3及学习JSON 8。
- 历史表的总时长、有效用时和效率在单元格内整体居中，总时长与有效用时只用m作单位，每列数字槽至少预留三位紧排数字并右对齐，按该列历史最大位数统一扩展；数字槽与单位m作为整体居中，所有行的m对齐。效率预留三位数字，百分号紧跟数字槽。历史缺失行仍显示居中的破折号。总时长和有效用时单元格显示的分钟数达到60时，悬浮显示对应的“x h y m”（如100 m提示1 h 40 m，60 m提示1 h 0 m）；不足60分钟和缺失值无提示。开始时间、结束时间、效率、复习词和新词沿用现有悬浮规则。
- 历史表只有日期、时段、状态三列保持当前固定宽度；其余八列以默认1040像素窗口下现有宽度作为固定比例，分配视口扣除三列后的全部可用宽度。开始和结束时间等宽，复习词和新词等宽，总时长和有效用时等宽（整数像素舍入可相差1像素）。窗口缩放、面板展开及纵向滚动条出现或消失时重新按相同比例分配，不累计舍入误差，不持久化列宽；沿用数据库及交换版本。
- 状态仅显示图标：补显缺失为灰叉，完成为绿勾，历史未完成为柔红叉，当前未完成为金色双三角快进。当前按锁定快照识别，暂停仍属当前任务；完成状态优先。悬浮提示分别为“未完成”“已完成”“未完成”“进行中”，无障碍文本继续区分四种状态。

- 该行右端显示每日新背开关：方框常显，开启时叠加超出方框的绿色勾，关闭时仅留空框。悬浮提示分别为“点击关闭每日新背单词”“点击开启每日新背单词”。点击即时保存，失败恢复数据库中的状态；无词禁止开启的提示使用图标上方Toast。开关存于settings键study17.new_words_enabled（1开启、0关闭），随学习进度交换；沿用SQLite 10、普通JSON 3及学习JSON 8，无需结构迁移。
- “十七天背单词设置”在每日新背行下显示“拼写时隐藏单词：全部”，四行作为紧凑分组，行间距4像素，子项文案不带句号；其下三行以↳标识子设置：记忆周期为[1/2/4/7/15，默认15]天后的单词、重点单词⭐、已记下单词。总开关有空框、勾选、半勾选三态；半勾选为外框内同色实心小方块，内外留空隙。点击空框或半勾选变全选并勾选三项；点击全选变空框并清空三项。操作任一子项后，有选中项即为半勾选（即使三项全选），全空则为空框。修改阶段阈值不改变勾选状态，子设置始终可操作。全选隐藏全部待拼写词，空框全部不隐藏；半勾选依次短路判断已启用条件：当前stage≥阈值（含所选阶段）、主词important、主词learned，任一命中即隐藏。阶段不按实际经过天数计算，stage=0的已完成词仍不参与拼写。设置作为完整配置在既有settings表内事务保存，失败恢复并提示；旧布尔开关开启映射为全选且三项全选，关闭或缺失映射为空框且三项全空，阈值均为15。读取配置到内存供拼写判断，不逐键查询数据库。
- 拼写隐藏仅在释义显示且首个正确字符输入后生效：主词只绘制黄色已输入前缀（空格保留位置），同时临时隐藏所属全部关联词的词名及音标，保留其词性和翻译，不折叠行。隐藏词名的悬浮提示不泄露内容。输错、Esc、Backspace、切词、失焦及其他现有进度重置操作恢复原显示；配置成功变更也清空进度。保持主词音标、复制及编辑规则，不修改词条或答案显隐状态，长前缀仍按原区域省略。
- 设置窗口关闭后（关闭按钮、Esc或其他关闭方式），键盘焦点统一回到当前页单词列表，保留仍有效的原单词、单元格、整组选中状态和滚动位置；不返回设置按钮或表单输入框，空列表仅获得焦点。此项不改变数据库或交换版本。设置窗口默认宽度约407像素、默认高度480像素（较640像素缩短四分之一），内容可垂直滚动，无“完成”按钮；所有配置修改直接生效并入库，删除仍需命令及二次确认。恢复默认快捷键按钮保持原尺寸，放在快捷键标题行最右端、底部对齐。沿用现有数据库及交换版本。
- “十七天背单词设置”“快捷键设置”“清空内容”三个大区块之间以半透明细横线及留白分隔，随内容一起滚动。
- 设置底部提供“清空内容”：说明“输入对应的确认信息删除对应的内容”，列出 `delete study record：删除学习记录。`、`clean vocabulary only：删除学习记录不包含的词汇。`、`remove all：删除所有学习记录和所有词汇。`。输入框仅绘制匹配前缀的半透明命令后缀，不自动填入；只有完整、区分大小写且无额外空白的三个命令之一才能启用确认。在输入框按Enter（含数字键盘）等同点击确认，复用同一二次确认入口；无效命令不弹窗。二次确认初始焦点和默认按钮均为取消，Tab/Shift+Tab可在确认、取消之间切换，Enter执行当前选中按钮；Esc或关闭仍取消。此项不改变数据库或交换版本。
- 删除前复用草稿清空确认窗口，明确删除范围与不可恢复性，默认Enter/Esc/关闭为取消。仅删除学习记录会保留词条及普通记忆状态；仅清理词汇按学习进度表（含stage=0）保留参与词；全部删除同时清空词条、学习进度和任务历史。每次操作一个事务，删除学习记录时同时移除settings中的study_last_add_new_vocabulary与study17.group_counter，保留快捷键及抽词偏好。成功后同步列表、历史、计时内存，不自动抽新词；删除正在编辑词时在警告中说明草稿将丢弃，确认成功才重置该草稿。
- 按钮提示使用当前实际快捷键，输入保护期间暂停业务快捷键。常规成功操作不显示状态栏；校验错误使用紧凑非模态浮动提示，重复词可定位已有词。

## 8. 数据结构与一致性

### 8.1 当前版本与存储

| 类型 | 当前版本 |
| --- | --- |
| SQLite | 10（由migration.SCHEMA_VERSION定义） |
| 普通词条JSON | 3（transfer.VERSION） |
| 学习进度JSON | 8（study_transfer.VERSION） |

默认数据目录为Windows `%LOCALAPPDATA%\\kkMemorizeVocabulary`，macOS `~/Library/Application Support/kkMemorizeVocabulary`；数据库为vocabulary.sqlite3，日志同目录。`--data-dir`可指定隔离目录。退出后复制数据目录可完整备份；更新/卸载保留个人数据。

### 8.2 表与约束

| 表 | 字段及用途 |
| --- | --- |
| words | id、text、phonetic（非空文本，默认空串）、normalized_text唯一、important、learned、sort_order正整数、created_at、updated_at；分类/排序号/ID索引 |
| related_words | id、级联word_id、text、phonetic（非空文本，默认空串）、position |
| senses | id、word_id或related_id二选一、pos（非空词性）、translation（非NULL文本，默认空串）、position |
| settings | key/value；快捷键、本机抽词偏好、最近抽词日期及组号高水位 |
| memorize_vocabulary_17day | word_id级联主键、group_number、stage、morning_done、afternoon_done、last_completed_on；阶段/最后日期索引 |
| study_task_history | id、task_date、afternoon、started_at、ended_at、duration_seconds、status、new_total、review_total、new_done、review_done |

- 学习阶段仅为0/1/2/4/7/15；阶段1最后完成日期为空，其余非空；双时段不能同时为1，stage=0清空双标记。
- 学习设置键为study17.words_per_group、study17.groups_per_day、study17.new_words_enabled、study_last_add_new_vocabulary（YYYY-MM-DD）及study17.group_counter；拼写隐藏使用study17.hide_word_while_spelling（0/1/conditional）及其.by_stage、.by_important、.by_learned、.minimum_stage子键。删除词条不回收组号。清空学习记录保留每日新背开关及抽词数量偏好。
- 设置批量清理不单独新增字段或迁移；删除学习记录的两种命令在同一事务清除进度、历史及最近抽词日期/组号高水位。
- 任务日期/时段唯一，afternoon为0上午/1下午，status为0未完成/1完成；数量、整数秒非负，已背数不超过总数。未完成结束时间为空，完成必有结束时间。
- 任务起止时间为带+08:00、精确到秒的北京时间文本，任务日期来自锁定快照，允许起止跨日；有效用时不由时间差计算。任务汇总无词条外键或词级明细。

### 8.3 迁移与事务

- 按001～010包内UTF-8 SQL脚本顺序升级，每步BEGIN IMMEDIATE持锁后重读版本，成功提交user_version；失败只回滚当前步骤，重启续迁，拒绝更高版本。失败关闭连接，禁止进入业务读取。
- v9→v10将主词和关联词释义的旧词性代码“其他”更新为else，不改变释义ID、内容、顺序或学习进度。普通JSON 3、学习JSON 6保持不变，旧代码“其他”作为兼容别名在导入/保存时统一转为else，新的界面及数据库输出使用else。
- v8→v9事务重建senses，保留ID、归属、词性、译文、顺序、外键及索引，为translation设置空串默认值并为pos增加非空白约束；空译文使用空字符串，不使用NULL。普通JSON 3、学习JSON 6保持不变：字段及类型未变，仅允许translation字符串为空，仍拒绝缺字段、NULL及非字符串，兼容已有文件。
- v7→v8为主词及关联词追加phonetic，旧数据默认空串；保存清理首尾空白，导入严格要求字符串（允许空串）。普通JSON升至3，学习JSON升至6，继续仅接受最新版本。
- 历史步骤依次处理基础词条、分类排序、学习表、最近抽词日期、六字段学习模型、任务历史、整数秒。v6→v7将毫秒四舍五入为秒，保留其他数据；旧库不补造不存在的任务历史。
- 新增迁移只追加脚本，不修改已发布脚本。以sqlite3.complete_statement分句执行，不用会隐式提交的executescript；SQL脚本随包交付并验证一致。
- 学习日05:00边界只改变运行时操作快照的日期归属，不改变已存任务日期、时间戳、表结构或交换字段；无需数据库迁移或交换版本升级。
- 所有数据值参数绑定，聚合保存、删除、排序及学习更新使用事务。UI仅在成功后更新；重复主词采用导入内容时原地更新，保留主词ID、创建时间及原有学习进度，不删除重建主词。
- 列表清空后自动删除沿用现有表、外键和任务计数规则。SQLite 10、普通文件 JSON 3、学习文件 JSON 8 和剪贴板 JSON 1 保持不变。

### 8.4 JSON交换

- 整词剪贴板是独立的普通文本 JSON 协议 `kkMemorizeVocabulary.word` v1，仅含格式、版本、`text`、`phonetic`、`senses`（每项 `pos`、`translation`）。带本协议标识但版本或结构无效时拒绝粘贴并提示，其他内容走原生粘贴。SQLite 10、普通文件 JSON 3、学习文件 JSON 8 沿用现有版本。

- 两种文件只接受各自当前实现的最新版本，拒绝旧版/未知新版；完整校验格式、字段、类型及内容后才处理草稿或写库，UTF-8文件使用临时文件原子替换。
- 词条文件格式为kkMemorizeVocabulary，包含words；每词包含text、phonetic、important、learned、senses、related及可选sort_order；每个关联词包含text、phonetic、senses。translation必须为字符串但可为空，名称和词性仍必填。释义/关联词数组顺序及正文保留，不交换本机ID或时间戳。重复对比包含音标。
- 学习文件格式为kkMemorizeVocabulary.study17，包含words、study_records、study_settings、task_history。进度以strip().casefold()词名绑定，词条与进度一一对应；历史包含全量汇总及原ID，校验ID/日期时段唯一、状态/结束时间与数量关系。
- 学习导出在同一读快照获取全部参与词（含未来到期和周期结束词）、进度、最近抽词日期、组号高水位、历史及学习设置，不写入运行中用时。学习JSON升级为v8，study_settings.hide_word_while_spelling改为完整对象，字段为mode（off/all/conditional）、by_stage/by_important/by_learned（三个严格布尔值）、minimum_stage（1/2/4/7/15之一）。off必须三项全空，all必须三项全选，conditional必须至少选一项。其余设置沿用原字段；缺失、未知、类型或状态组合错误均拒绝。v7及更早文件按仅接受最新版策略拒绝，普通词条JSON保持v3，SQLite保持10；仅使用既有settings表，无需迁移。

### 8.5 导入流程

- 普通页导出当前分类/搜索的全部主词（含视口外），可识别词条或学习文件；学习页只接受学习文件。无效结构/内容/编码/版本在普通入口统一提示“数据结构不合法，导入失败”，实际读写错误保留原因。
- 普通词条和学习进度的导入/导出文件选择框每次默认打开系统桌面目录；导出仍预填原有默认JSON文件名，不修改实际选择的保存位置。沿用数据库及交换版本。
- 合法学习文件先提供“导入单词和进度”“仅导入单词”“取消”，已有进度或任务历史时明确整体覆盖；取消不改数据/草稿、不切页、不抽词，不重复打开文件选择器。
- 普通词条及学习文件的词条导入，在完整校验后、判重和入库前，清理主词及全部关联词音标首尾空白和两端的正斜杠“/”（含重复或仅单侧斜杠），保留音标正文中的斜杠及其他字符；清理后为空则使用空音标。对比候选、采用及点击音标同步均使用清理后的值，不因清理回写导入JSON；之后切换右侧星标/记忆状态时仍只写对应状态字段，文件中的原音标保留。手动输入/编辑及已有本地音标不批量修改。沿用SQLite 10、普通JSON 3及学习JSON 8，无需迁移。
- 词条先导入非重复项，再逐条/批量比较重复主词。清理首尾空白后，拼写、音标、顺序化释义/关联词、重点和记忆状态全相同则跳过；比较区分大小写，不考虑ID、排序号或时间戳。
- 对比窗口标题为“导入重复词对比选取”。顶部提示为水平居中的“导入新词：x 个，重复单词：y 个，[鼠标左键图标] 卡片立即采用，[鼠标右键图标] 相应位置修改或同步单词信息”，宽度不足时换行；x为已导入新词数，y为剩余重复记录数，随采用更新，仅数字使用学习页复习计数的浅绿色，不放大字号。两侧标题分别为“本地单词”“导入单词”，各自与文字为“全部选用”的批量按钮合为一行（标题在左、按钮在右，间隔约3个空格），整组在对应半页居中，沿用原整批采用行为。不显示底部关闭按钮，标题栏关闭或Esc保留已采用的结果并结束对比。两侧星标和记忆状态图标的原悬停提示前统一加鼠标右键图标。卡片的已记下图标悬停提示为“已记住，点击改为待记”，待记为“待记，点击标记为已记下”；星标提示为“取消重点”或“设为重点”。
- 普通词条和学习进度导入成功后的提示统一为“新增 x 个主词，覆盖 y 个主词。”，x为新增主词数，y为手动采用导入卡片实际覆盖的不同主词数；仅数字使用上述浅绿色，不放大字号。自动处理按卡片独立计数，不重复计入手动覆盖数量，最终导入提示不重复追加自动合并统计。
- 两侧标题组正中间增加“自动合并”按钮，左右标题组仍在各自半页居中，卡片等宽。规则提示分“一、不自动合并的标准：”“二、合并逻辑：”两节，各条目以4个空格缩进并独立从1开始编号。第一节列出同词同词性导入译文更长（本地空译文除外，含关联词）、任一词自身重复词性、任一侧关联词重名三种整组跳过标准；第二节精简说明本地优先、关联词追加/同名匹配、空音标补齐、空译文/新词性补齐、字符计数和本地标记/排序保留及自动保存。保留原有合并规则，提示使用无定时关闭的独立浮层，鼠标停留超过5秒仍可阅读；移开、点击、窗口失活或关闭时隐藏，不影响其他提示的5秒限制。
- 自动合并将主词及其全部关联词作为整体，先检查双方所有词（包括仅一方拥有的关联词）：任一词自身存在重复词性，或同一侧关联词按strip().casefold()名称重名，整组跳过；主词与其关联词同名不算关联词重名。之后主词及唯一同名关联词逐项比较：本地没有的词性按导入顺序追加；同词性本地空译文补入导入译文；本地译文非空时，导入更长则整组跳过，否则保留本地，不判断语义。任一条件阻止合并时，连音标和新增关联词也不提前保存。
- 检查通过后，主词及同名关联词仅本地音标为空时补入；额外关联词整条按导入顺序追加。本地原有拼写、释义及关联词顺序、主词ID、收藏、已记下、排序和学习进度保留。只保存本地词库，不写回导入文件；通过但无内容变化的卡片不写库，视为无需修改并移除。
- 每次点击自动合并按剩余卡片顺序逐条与事务内最新本地内容比较，同名多条候选累计合并，跳过一条仍继续后续卡片，每张卡片本次只检查一次。整次后台独立连接事务统一提交，任一数据库错误整批回滚，卡片及统计不推进，可重试；成功后统一移除已处理卡片，同步剩余同名左侧内容并保留滚动位置。每次成功处理后仅弹出一个标题为“自动合并完成”的小提示框，分三行显示“合并并修改 a 条”“无需修改 b 条”“剩余待人工 c 条”，没有可合并项时也提示本次结果；对比窗口不设置常驻统计区域。确认提示后继续人工对比，全部处理完则退出对比窗口。普通和学习文件两种入口共用，学习进度恢复继续遵守原导入模式。沿用SQLite 10、普通JSON 3及学习JSON 8，无需迁移。
- 导入对比界面的左右卡片采用类似单词列表的分栏布局：左侧词名和可选音标分为上下两行独立展示，音标起点与对应词名对齐，显示时去掉两侧斜杠，保留弱化样式（不修改保存内容），空音标不占行。右侧按原顺序每条释义一行，词性和翻译分列；同一个词有多条释义时共用左侧区域。扣除固定词性列、图标及间距后，单词与翻译按3:10分配可用宽度，优先给释义留空间。单词、关联词、音标、释义各自单行展示，内容超宽时末尾显示三个点“...”，仅被截断时悬停提示完整原文；释义正文中的换行在单行预览中按空格显示，提示保留原换行。列宽变化立即更新省略和提示。每对同一主词的左右卡片等宽等高，高度取两侧内容所需高度的较大值，较短侧内容保持顶部对齐、多出的空间留在底部；不同主词的卡片对仍按各自所需高度紧凑排列，内容更新及窗口缩放后继续保持成对等高。对比窗口初始高度随内容调整，不额外拉高所有卡片。关联词在主词释义之后另起一组，词名前绘制与单词列表一致的折角箭头，音标与关联词文字对齐；主词与关联词的右侧释义列对齐。重点星标和记忆状态图标悬浮显示在每张卡片右上角边框，不参与内容布局、不占单词或释义列宽；重点显示金色星星，非重点显示暗星，已记下显示绿色实心圆，待记显示绿色空心圆环，悬停说明对应状态。释放原图标列空间给内容，整卡点击采用行为保留。此项沿用现有数据库及交换版本。
- 排序号全有时稳定升序，否则按文件顺序；导入新增词追加到目标分类，主词仅按规范化名称判重。对比卡片左侧保留本机；右侧单条或“全部选用”统一即时原地更新本地主词，完整采用导入拼写、音标、释义、关联词、收藏和已记下状态，保留本地主词ID、创建时间、学习进度及任务历史。记忆状态与事务内最新本地状态相同时保留原分类排序号，改变时才分配目标分类末尾排序号，导入排序号不覆盖本地排序。同名卡片同步最新内容；批量右侧采用在一个事务中按候选顺序读取并更新，最后采用者生效，排序只在实际状态变化时调整，失败整批回滚内容、状态、排序及排序高水位。关闭保留已处理项及未处理的本机词。沿用SQLite 10、普通JSON 3及学习JSON 8，无需迁移。
- 对比卡片右上角的星标、记忆状态图标仅用鼠标右键切换，不触发整卡采用、不移除卡片。左侧修改立即保存本地词库，沿用普通列表的记忆分类末尾排序规则，并同步所有同名左侧卡片；右侧修改立即原子写回本次导入的原JSON文件中对应记录的important或learned，再更新候选状态，之后采用该候选使用修改后的值。文件内同名候选按原始记录位置分别修改，不影响其他候选、词条顺序、可选排序字段、音标、释义、关联词及学习文件的进度/历史/设置；普通和学习文件入口均支持。关闭/Esc保留已成功保存的状态修改；文件或数据库保存失败提示原因且保持修改前状态，可重试。导入源文件自读取或上次写回后被外部修改时拒绝覆盖并提示重新导入。仅右键图标操作修改文件，选择卡片不额外写回。沿用SQLite 10、普通JSON 3及学习JSON 8，不增加交换字段或数据迁移。
- 右键点击右侧“导入单词”卡片的主词音标，将导入清理后的完整音标即时保存到本地主词；关联词按strip().casefold()拼写定位本地顺序中的第一条同名关联词。右键主词或已有同名关联词的词性标签、译文格（含空白），仅同步点击的这一条释义：有同词性时覆盖本地第一条同词性释义的译文，无该词性时追加到末尾。空译文允许同步，保留词性和释义行，不走清空删除规则。只更新目标字段及更新时间，保留主词ID、其他内容、顺序、标记和学习进度，不回写JSON。保存失败保留原数据和卡片，可重试。
- 本地尚无同名关联词时，右键该导入关联词的整组区域（拼写、箭头、音标、词性、全部译文和组内空白）追加完整关联词到本地末尾；判重只比较关联词列表，忽略大小写及首尾空白。事务内重新判重，已存在不重复追加。成功后所有同一本地主词的左右卡片同步内容/命中规则/提示；该关联词转为已有词，音标及释义可分别右键同步。不采用、不移除卡片，即使两侧相同也保留待选，关闭保留成功修改。
- 卡片任何位置左键均立即采用，包括星标、记忆状态、音标、词性、译文和关联词；这些位置右键仅修改/同步，其他位置右键无操作，不弹默认右键菜单。整个对比窗口（含顶部按钮）禁用空格、回车及数字键盘回车的按下/释放/快捷触发，保留Esc关闭及Tab焦点导航；限制不影响另外弹出的消息框。
- 导入音标、可同步词性/译文的操作提示分别为“[鼠标右键图标] 同步到本地音标”“[鼠标右键图标] 同步到本地译文”；被省略时在操作提示前显示完整原文。已有同名关联词拼写和箭头无关联词同步提示。本地缺少的关联词整组只显示“[鼠标右键图标] 同步到本地关联词”，优先于全文、音标及译文提示。提示使用现有鼠标图标且在文字前；resize、内容/本地状态更新后提示保持正确，沿用全应用最长5秒规则。SQLite 10、普通JSON 3及学习JSON 8保持不变，无需迁移。
- 全量恢复前暂停旧任务。词条阶段之后，独立事务整体替换学习进度、任务历史及相关学习设置；失败一并回滚此阶段，已导入词条保留并说明。仅导入单词不替换进度、历史或四项学习设置。恢复设置与进度、历史同事务提交，任一写入失败全部回滚；恢复每日新背开关不调用开启抽词入口，不立即抽词或重新分组，后续显式刷新按恢复的设置执行。启动时无可抽词则关闭每日新背的既有规则保留。
- 恢复成功清除旧计时内存，按当前日期/时段读取任务但不抽词，未完成记录以暂停载入；仅词条刷新原快照，不额外推进学习。
- 文件/数据库耗时处理在后台独立连接执行，半透明全窗口遮罩阻止输入、重复触发及关闭，主线程维持绘制；文件选择、确认及对比阶段可交互。任务结束/失败移除遮罩，后台不访问Qt控件。
- 重复词对比窗口打开期间，后台主页面保持打开对比前的显示，不因音标同步、星标/记忆状态切换、逐条或批量采用而全量读取词库或重建主页面；弹窗内对应卡片、状态和计数照常即时更新，数据库/导入JSON仍按原规则立即保存。关闭、Esc或处理完全部卡片退出对比后，由导入流程统一刷新主页面一次；普通导入不在打开对比前额外刷新。学习文件导入在退出对比并按所选模式完成进度恢复/载入后统一刷新，失败路径仍按既有规则刷新已保存的结果。沿用SQLite 10、普通JSON 3及学习JSON 8，无需迁移。
- 对比弹窗的局部操作维持内容区与视口等宽，仅按卡片所需高度调整滚动范围，避免自然尺寸调整导致全体卡片反复测量和省略重算；采用卡片时利用Qt当前事件内的绘制合并，不批量关闭/重启整个滚动区域及全部子控件的绘制；维持成对等高及原像素滚动位置。导入源在后台首次读取时建立状态字段的JSON位置索引，切换右侧星标/记忆状态仅替换对应原记录的布尔值文本，不再解析和重新排版整个文件，保留其他原文、缩进、转义及字段顺序；仍逐次检测外部修改并完整原子保存，失败不推进内存快照，可重试。此项不改变即时保存、取消/失败保护或数据版本。

### 8.6 独立 PDF 词表转换工具

- `tools/pdf_vocabulary/` 提供命令行 Python 工具，读取用户提供的结构化“高考大纲词3500个（乱序版）”PDF；默认只转换第1–116页编号主表，不转换最后的分组表。直接读取文本层，不使用OCR、联网词典或自动补全，不内置或打包分发词库。
- 输出普通词条JSON、按页保留的原始提取文本和JSON来源/异常报告；报告保存每条来源页码、原编号、原词头、原音标、原释义及处理决定。只写用户指定的输出路径，由用户在程序中手动导入，不访问个人默认数据库。输出路径不得与输入PDF或工具源文件重合。
- 主词括号内的变形/拼写说明剥离后记入报告，不生成关联词；保留原有拼写、大小写、粘连及短语空格，不自动纠错。忽略大小写合并同名主词，保留首次出现的拼写与位置，有序合并并去重词性/释义；默认非重点、待记，关联词为空。
- `a.`规范化为`adj.`，`ad.`为`adv.`，`vt.`/`vi.`为`v.`，`int.`为`interj.`；不支持、缺失或无法确认的词性记为`else`并报告原标记。多词性和释义用`&`明确逐项对应时分别提取，否则每种词性共享完整原释义，不凭语义猜分。
- 音标最多保存一个：完整美式优先，否则取原文首个完整音标；美式只有替换片段时不猜测展开，回退完整音标并报告。合并词的候选按同一优先级选择，优先级相同时取首次出现者，冲突记入报告。
- 原资料可识别的错误、缺损保持原文并报告；无法识别词头的`#VALUE!`记录只进入报告。报告不声称已完成词典级纠错，输出数量以实际解析、合并及排除结果为准，不强行达到3500。结构性解析失败必须报错，不静默丢行。
- 写出前使用现有领域校验及普通JSON导入校验。工具作为源码辅助程序独立运行，专用运行说明和依赖放在自身目录，不增加主程序依赖或界面入口。沿用SQLite 10、普通JSON 3及学习JSON 8，无需迁移。

## 9. 模块边界与内部接口

- `domain`：WordEntry、RelatedWord、Sense、词性和默认快捷键定义，输入校验。
- `storage`：数据库初始化与迁移、读取聚合、保存聚合、删除、状态变更、两个分类的最大排序号、拖拽及随机排序、快捷键读取与写入；负责事务与 SQL。排序统一通过 batch_update_sort_orders 批量更新，事务提交后发布最大值。
- `transfer`：JSON 文件格式、严格校验、完整词条序列化、导入源快照及按原记录位置原子写回状态；`import_dialog`：重复词左右对比、左键采用/右键局部操作及提示优先级、逐条或批量选择及事务覆盖。`storage.import_entries`保留候选原始记录位置，`replace_imports`共用单条/批量原地更新及记忆状态变化时的末尾排序规则；`set_phonetic`和`sync_import_translation`事务更新主词或第一条同名关联词的目标字段，`append_import_related`事务判重后追加完整关联词；`window`将普通/学习导入源快照传入对比窗口。
- `import_merge`：不访问Qt或数据库的整组合并判断、跳过原因和自动处理结果数据对象；`storage.auto_merge_imports`在一个事务内按候选顺序与最新本地词比较并保存；`import_dialog`提交成功后更新卡片及统计，并用一次性小弹窗提示本次结果。自动合并与手动覆盖分别计数，`window`最终导入提示保持原文。
- `word_clipboard`：单词内容校验和独立剪贴板协议；`word_paste`：限定文本框 Ctrl+V/Command+V 的 Qt 适配。`table` 维护行内预览及原始快照，`WordBlock` 负责表单草稿更新与撤回，`window` 路由复制并提示，`storage` 一次事务替换目标词及其释义。SQLite 10、普通文件 JSON 3、学习文件 JSON 8 和剪贴板 JSON 1 沿用现有版本。
- `busy_overlay`：全窗口半透明遮罩、旋转指示、输入保护及后台任务等待，只在界面线程绘制/处理控件；`transfer_jobs`：后台任务独立Repository连接的生命周期及排序高水位同步，返回普通数据对象，不访问Qt控件。
- `shortcuts`：规范化与校验、按作用域分发、设置生效和失败恢复；`native_shortcuts`：仅在 Windows 主窗口激活期间接收原生组合键，避开中文输入法拦截并在离开窗口或暂停时释放；其他平台只使用Qt窗口快捷键。
- `widgets`：搜索框及结果数量显示、词性选择框、释义输入行、主词/关联词输入组、确认窗口、图标绘制。搜索结果数量由数据库分页结果提供，显示全部命中主词数。
- `table`：视图行投影、自定义绘制、行高与换行、遮罩、点击/双击分发、就地编辑。
- `table_style`：仅负责统一列表底色、选中底色、分隔线和译文侧分组竖线；接受现有Qt表格投影与绘制矩形，不维护业务状态或处理事件，不依赖`table`及页面/存储模块。
- `table_header`：统一处理可调分隔线的命中、拖动及左键双击复位；默认尺寸、最小宽度、合法区间、窗口收缩分配、运行内宽度记忆及换行行高由`table`协调，不读写数据库。此轮不改变SQLite或JSON版本。
- `word_name_editor`：列表词名输入及其下方音标浮层的几何、焦点归属和生命周期；`table`协调键盘及一次提交两项，`window`将二者写入同一次聚合保存，不单独追加数据迁移。
- `review_navigation`：共用方向键解析、受列表面板范围约束的键盘事件路由；将功能按钮上的导航交给当前WordTable.navigate_entries，不维护选择或业务状态。
- `study_input`：十七天页词性键映射、主词拼写进度与重置结果；不持久化、不操作Qt控件，列表协调按键、临时绘制及揭晓/记下请求。
- `input_placeholder`：表单拼写和翻译框的空输入提示绘制，复用回车键图标及PlaceholderText颜色，处理输入法预编辑、尺寸和字体变化，不拦截输入或访问数据库。
- `input_focus`：主窗口及所属对话框的输入焦点策略，新聚焦输入定位末尾，主窗口按钮在空白点击后释放焦点；不处理词条、保存、选择导航或快捷键业务。
- `form_focus`：区分表单内输入、操作控件、空白与表单外焦点，维护表单操作上下文并通知空白点击；不选择关联词或修改草稿。`window`据此决定按钮提示、插入位置与具体/末尾删除目标。
- `pos_picker`：词性浮层的完整选项、屏幕内定位、选择/取消信号及共用词性按键解析；不调用窗口或数据库，列表编辑代理负责提交，底部PosCombo复用按键解析。
- `draft_reset_dialog`：清空/取消编辑共用的模态确认、默认取消及原按钮位置对齐；不修改表单或数据库，由窗口在确认后重置输入。
- `unsaved_input_dialog`：处理未保存草稿的共用模态选择，仅有保存/放弃，初始不聚焦按钮，关闭/Esc取消；由window在明确选择后保存或丢弃输入，不读写数据库。
- `cleanup_input`：设置清空命令的半透明后缀绘制，不修改文本、不提供自动补全；`shortcuts.SettingsDialog`负责命令校验及共用删除警告，`window`协调成功后的草稿、计时和列表刷新，`storage.clear_content`负责事务删除及抽词状态清理。
- `drag_reorder`：主词及关联词拖动共用的插入位置计算、动画时长、预览边框和边缘滚动规则，不依赖业务窗口或存储。
- `form_reorder`：关联词输入组及词内释义行共用的拖动事件、快照预览和范围保护，不重建输入控件、不读写数据库；窗口编排blocks排序，WordBlock处理释义行排序并通知更新Tab顺序，拖动期间暂停业务快捷键，结束恢复原暂停状态。
- `list_query`：存储层数据库分页、精确搜索排名、计数/锚点/边界ID及批量聚合，提供独立只读查询连接，不改变数据库结构。
- `list_state`：普通三分页缓存、唯一搜索缓存、位置、显隐及缓存有效性，不访问Qt或SQL；`list_jobs`：后台只读查询、请求合并、取消和结果代次，不访问控件；`pagination`：分页控件及数字输入，只发出请求。
- `list_sync`：已提交变更、位置映射和同步计划的统一规则，不访问Qt或SQL；普通缓存与学习页只执行同步计划。
- `list_controller`：普通分页的窗口编排混入，管理已应用快照、加载/焦点意图、缓存路由及写入后局部更新，SQL仍由存储层执行；`window`保留表单、对话框和应用入口协调。
- `window`：已提交查询快照、分页/缓存协调、表单编辑状态、焦点意图、设置窗口与提示；输入文字与已应用条件独立，不能用未成功的输入解释旧列表。
- `learning`：北京时间操作快照、学习任务/历史数据对象及阶段间隔计算；`study_page`：独立学习表格、刷新、计时按钮与上下午先后顺序操作；`storage` 提供生成、查询、完成学习任务及历史汇总的事务接口。
- `study_completion`：学习空列表的两行提示（已完成或暂无待背单词）、可点击刷新图标和链接文字及视口居中定位，只发出刷新请求；是否显示和实际刷新由`study_page`决定，不读写数据库。
- `study_timer`：单调时钟累计、应用空闲及Windows电源事件（仅Windows）、内存运行/暂停状态，持久化通过Repository；其他平台依赖单调时钟和空闲检测。`study_history`：只读历史表格、缺失时段投影、日期分组及独立折叠面板，不拼接SQL、不生成任务。
- `migration`：按版本读取UTF-8 SQL包资源，逐步事务执行并提交版本号；`migrations/`：历史建表与数据升级SQL。`storage`连接后调用此入口，升级失败关闭连接，成功后才读取业务状态。新增版本追加脚本并登记，不回改已发布脚本。
- `study_transfer`：独立学习进度JSON的词名绑定快照及带ID的任务历史、完整文件校验与UTF-8原子文件保存；`storage`提供一致性导出快照及全量进度恢复事务，`window`复用词条重复选择界面协调两个导入阶段。
- `app`：命令行入口、用户数据目录、日志、主题、程序生命周期。

数据通过 Python 数据对象在层间传递，UI 不拼接 SQL；所有数据值使用 SQL 参数绑定。没有对外网络 API。

## 10. 开发运行与分发

Windows `start.bat` 与 macOS `start-macos.command` 使用本地源码启动程序，不在启动时自动检查或拉取代码更新；需要更新源码时由使用者手动执行Git操作。本项不改变SQLite、JSON或剪贴板协议版本。

源码环境、隔离数据目录、测试、构建命令及辅助工具统一见[开发指南](开发指南.md)。Windows构建交付完整程序目录、便携ZIP和安装程序；macOS在Apple Silicon主机上构建`.app`与ZIP，首轮不签名、不公证。发布页实际附件由维护者选择上传，不把源码ZIP或构建启动器当成安装包。

日常构建默认执行`tests/build-smoke.txt`中的关键检查，覆盖持久化、迁移、导入导出、学习进度和代表性界面交互，失败立即停止构建。清单仅对核心存储和迁移模块整文件运行，其他模块明确列出关键测试函数，避免新增专项或界面参数矩阵自动扩大默认构建范围。完整界面参数矩阵用于显式开发回归，可通过`build.ps1 -FullTests`随构建执行；默认双击构建启动器不运行全量矩阵。两种模式均执行成品源码/SQL一致性检查及依赖检查。使用Conda作为Python基础运行时时，显式收集该运行时Library/bin中的SQLite、FFI、压缩及SSL依赖，不依赖用户系统PATH。生成ZIP和安装包前，在独立数据目录执行成品首次启动及同目录重启冒烟；超时、非零退出或缺少成功结果均中止构建。此构建策略不改变程序行为、数据库或交换格式版本。

## 11. 验收标准

- 数据库500主词分页/组不拆、普通三缓存与唯一搜索缓存、显隐隔离、静默读取失败、后台请求去旧、写后局部更新及页尾补位定位。4000词主验收、10000词增长验证；翻页约300毫秒、搜索250毫秒等待结束后约500毫秒目标，记录SQL/聚合/布局耗时，不达标报告原因，不降低标准。
- 词条聚合、多释义/关联词、唯一校验、级联删除、保存/导入/排序失败回滚及重启恢复。
- 四页鼠标/键盘、遮罩显隐、复制/编辑、Tab/F2导航、输入法、拖动/取消/滚动、独立草稿覆盖及确认保护、音标双目标显示、允许/锁定的列宽边界。
- 快捷键提交先于生效、冲突拒绝、失败回退、改键重启保留及原生路径去重。
- 抽词固定批次/零词、时段边界/快照、逾期/阶段结束、分类计数、已完成词展示与重复记下保护。
- 整数秒取整、暂停/继续/空闲/关闭/休眠、用时写入频率、历史静态与顶部实时分离、四态图标及缺失补显。
- 各版本迁移、迁移断点/失败、JSON最新版本及完整校验、词条与进度覆盖/取消/仅词条、历史往返及事务失败。
- 默认/最小窗口、125%和150%缩放不重叠；EXE离线无控制台启动，隔离首次保存/重启、更新/卸载保留数据。
- 成品模块和SQL资源与源码一致，不混入外来ICU/API-set DLL。测试数据库与个人数据分离。

具体测试数量、截图及成品验证结果只记录在[验收记录](验收记录.md)，历史条目不覆盖当前规范。
