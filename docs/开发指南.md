# 开发指南

## 从源码运行

使用 Windows x64 和 Python 3.12 x64，在 PowerShell 中执行：

```powershell
git clone https://github.com/whyCanNotKK/kkMemorizeVocabulary.git
cd kkMemorizeVocabulary
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.lock.txt
.\.venv\Scripts\python.exe main.py --data-dir artifacts\development
```

开发、测试和演示使用隔离的 `--data-dir`，不向默认数据库写演示词。依赖安装需要联网，程序运行可离线。配置好环境后，`start.bat` 可启动源码程序；默认使用个人数据目录，也可传入 `--data-dir`。

## 测试与冒烟检查

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe main.py --smoke-test --data-dir artifacts\source-smoke
```

测试使用临时数据库。重复运行同一隔离目录的冒烟检查可验证重启恢复；结果和截图保存在指定目录。需要离屏检查时可设置 `$env:QT_QPA_PLATFORM='offscreen'`，缩放检查可设置 `$env:QT_SCALE_FACTOR='1.5'`。

用例以当前项目设计为准，旧行为改变后更新对应断言；已有专项用例覆盖的重复检查应移除，共用逻辑避免无新增覆盖的参数笛卡尔积。公共测试环境在每轮测试中初始化一次应用主题及空数据库模板，每个用例复制出独立磁盘数据库；迁移专项仍自行创建各版本数据库，测试真实升级和回滚。开发全量回归使用上面的pytest命令；日常打包使用下述关键检查清单。

## 打包

双击仓库根目录的 `BuildInstaller.exe`，或执行：

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

默认构建检查Python和锁定依赖，准备Inno Setup，执行`tests/build-smoke.txt`中的关键检查，失败即停止，再生成并验证程序、便携ZIP和安装程序。清单保留数据库迁移/回滚、词条/学习数据交换、学习进度、关键编辑和快捷键等验证；完整界面参数矩阵不在每次日常打包时重复运行。`BuildInstaller.exe`调用当前目录的`build.ps1`，无需重编译启动器即可使用此默认行为。

需要完整回归后再打包时，显式执行：

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1 -FullTests
```

首次准备依赖/构建工具需要联网。两种模式均保留成品模块、SQL资源及外来DLL检查。构建日志位于`build/installer-build.log`，输出为：

- `dist/kkMemorizeVocabulary/`：完整程序目录，运行其中的 `kkMemorizeVocabulary.exe`。
- `dist/kkMemorizeVocabulary-windows-x64.zip`：便携包，解压后保留包括 `_internal` 在内的完整目录。
- `dist/kkMemorizeVocabulary-Setup.exe`：安装程序。

发布前检查包内模块及迁移脚本与源码一致、没有外来 ICU/API-set DLL，并在隔离目录验证启动、保存和重启。发布附件由维护者选择上传，构建输出不代表每种附件都已上传到 Releases。

## 数据与交换文件

个人数据默认位于 `%LOCALAPPDATA%\kkMemorizeVocabulary\vocabulary.sqlite3`；日志也在该目录。完整备份先退出程序，再复制数据目录。安装更新及卸载保留个人数据，`--data-dir` 可指定其他位置。

普通 JSON 交换词条；学习 JSON 还包含进度和全部任务历史。导入学习进度会整体替换本机进度及历史，选择“仅导入单词”则保留它们。支持的版本及事务规则统一见[项目设计说明第8节](项目设计说明.md#8-数据结构与一致性)。

`scripts/extract_practice_words.py` 可将特定旧练习 TXT 转成词条 JSON，并输出来源报告；它生成的 `n.` / `1` 是占位释义，需要自行整理，不是词典翻译。示例：

```powershell
.\.venv\Scripts\python.exe scripts/extract_practice_words.py input.txt -o artifacts\practice-import\words.json
```

工具按每行首词或已登记短语确定主词，忽略大小写合并重复主词，并按首次出现顺序补充、去重关联词，排除与主词自身重复的关联项。短语和例句排除由随附规则文件维护；保留原始拼写、大小写、连字符及撇号，不自动纠错。报告记录来源行号、短语识别、排除及标点清理。默认UTF-8（允许BOM），可指定编码和规则文件；输入、输出、规则和报告路径必须互不相同。
