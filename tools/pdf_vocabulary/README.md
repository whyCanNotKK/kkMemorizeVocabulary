# 结构化 PDF 词表转换

用于提取《高考大纲词3500个（乱序版）》PDF 的编号主表，生成当前程序能导入的普通词条 JSON v3。独立命令行工具，无界面入口；不写入个人数据库。**适配这份PDF的表格布局，不是通用PDF/OCR或词典纠错程序。**

## 运行

在项目根目录的 PowerShell 中执行（输入路径包含空格或中文时保留引号）：

```powershell
.\.venv\Scripts\python.exe tools\pdf_vocabulary\extract.py "G:\myDoc\study\English\剑桥雅思资料\高考大纲词3500个（乱序版）.pdf" -o artifacts\pdf-vocabulary\gaokao3500.json
```

也可以使用 Python 3.12 的单独虚拟环境，安装此目录的 `requirements.txt` 后运行；保留整个项目目录，因为输出使用项目现有领域对象和JSON校验。主程序已安装的 PySide6 含 QtPdf 模块，无需增加依赖。转换离线完成，不调用OCR、词典、大模型接口或其他在线服务。

默认生成三份 UTF-8 文件：

| 文件 | 内容 |
| --- | --- |
| `gaokao3500.json` | 可从主程序普通页面的“导入单词”按钮导入 |
| `gaokao3500.raw.txt` | 按页保留的原始文本层提取结果 |
| `gaokao3500.report.json` | 统计、编号缺口、逐条来源、异常及合并记录 |

`--raw`、`--report` 可分别指定另外两个输出路径。默认 `--first-page 1 --last-page 116`，排除最后4页另一套无音标分组表。所有页码从1开始。输出文件存在时会替换；请另选文件名保留旧结果。输入PDF和工具源文件受路径校验保护，不会被输出覆盖。

## 已确认处理规则

- 按实际提取数量输出，不凑3500；原编号缺口记入报告，不自动补词。
- 跨行词头、音标和释义按原表格连续文本拼接；原行内空格保留，音标去排版空白。
- 保留原拼写、首次大小写及粘连形式。词头括号里的变形/拼写说明和明确的等号别名说明只保存在报告，不生成关联词。
- 忽略大小写合并重复主词，保留首次位置；“词性＋释义”有序去重。`March`与`march`也会合并，这与程序判重一致。
- `a.`→`adj.`、`ad.`→`adv.`、`vt.`/`vi.`→`v.`、`int.`→`interj.`；不支持、缺失或无法确认的词性使用`else`，原标记留在报告。
- `adj&v.清晰的&清除`等明确按`&`对应时拆开；`n./v.通道,入径,存取`等无法精确分配时，两词性各保留完整原释义。
- 每词最多一个音标：完整美式优先，其次原文首个完整音标。`(US)-berɪ`等片段不猜测展开；合并词同级取首次出现者。这里的“完整”仅指未以连字符标示替换片段，**不意味着经过词典准确性验证**。
- 默认非重点、待记、无关联词；可识别的源错误/残缺保持原文并报告，词头为`#VALUE!`的记录只进入报告。
- 报告的`records`含每条来源页码、原编号、原始文本、候选内容、动作和异常；`entries`列出每个最终主词及其所有来源。统计`issue_counts`可按异常代码定位记录。

**原PDF含音标、释义错配和截断，生成JSON会保留这些源错误。报告也不代表对全部词条完成了词典级审校。** 结构性错误会终止转换，不静默丢行；解析与主程序校验通过后才开始写输出，JSON最后发布。三份文件各自原子替换，不承诺跨文件事务。
