# kkMemorizeVocabulary

[English](README.md) | **简体中文**

一个适用于 Windows 10/11 x64 的离线单词本，界面为中文。用于整理自己的单词和释义、遮住答案复习，以及按十七天复习计划背单词。所有数据保存在本机。

## 安装

1. 打开 [Releases 发布页](https://github.com/whyCanNotKK/kkMemorizeVocabulary/releases/latest)。
2. 在 **Assets（附件）** 中下载 **kkMemorizeVocabulary-Setup.exe**。
3. 双击安装程序，按提示完成安装，再从开始菜单或桌面快捷方式打开软件。

安装包已包含运行环境，无需另装 Python。

## 准备自己的单词

**软件不内置词库或词典，需要自己输入或导入单词和释义。**

- **手动输入**：在录入区填写单词、词性和释义后保存；可选填音标，支持多条释义和关联词。
- **导入词表**：点击导入按钮，选择本软件支持的 JSON 单词文件；也可以将已有词条导出，供后续使用或备份。

单词放入“待记”后，打开“十七天背单词”即可开始学习。

源码运行、测试和打包方法见[开发指南](docs/开发指南.md)。
