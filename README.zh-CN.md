# kkMemorizeVocabulary

[English](README.md) | **简体中文**

一个完全离线的 Windows 单词本，支持多释义与关联词整理、遮掩答案复习，以及独立的**十七天背单词**学习页。基于 Python、PySide6 / Qt Widgets 和 SQLite，数据保存在本机。

[下载发布版](https://github.com/whyCanNotKK/kkMemorizeVocabulary/releases) · [项目设计说明](docs/项目设计说明.md)

## 主要功能

- **十七天背单词**：每日抽取新词、固定分组，上下午分别学习，按阶段安排复习。
- **词条整理**：多词性、多条释义、多行翻译与关联词，支持重点星标和待记 / 已记下分类。
- **清晰界面**：深色主题、对齐的释义与分组竖线、整组选中高亮，以及可折叠录入区。
- **快捷复习**：点击遮罩揭晓答案，点击词名复制；支持键盘选词，切换标签页保留滚动位置。
- **编辑与排序**：双击就地修改，搜索单词和译文，整组拖拽排序或随机打乱待记词。
- **本地保存与交换**：词条、学习进度、顺序和自定义快捷键持久保存；JSON 导入导出支持重名词对比。

适用于 Windows 10/11 x64，界面为中文。成品自带 Python / Qt 运行时，无需另装 Python，可离线运行。

## 十七天背单词

1. 先将单词加入**待记**，上午打开**十七天背单词**页。默认每天随机抽取最多 **30 个**未参与的新词，按 **3 组、每组最多 10 个**分组，当天不重复抽取或补抽。
2. 每轮先完成上午学习，再完成下午复习。阶段为**第 1、2、4、7、15 天**，后续分别按实际整轮完成日期间隔 1、2、3、8 天安排；漏学保留进度。
3. 学习列表聚焦并选中单词后，按**回车**揭晓答案，再按回车“记下”并选中下一词。

双击单词名称、已揭晓的词性或释义可直接修改，关联词同样支持。按Enter、离开单元格或使用保存快捷键后直接保存到普通列表共用的主词记录，Shift+Enter在释义中换行，Esc取消；四个列表共用此编辑按键规则，学习分组与进度保留。

时段按**北京时间（UTC+8），15:00 起为下午**。跨时段或跨日后，刷新或重新进入页面即可更新。学习进度独立于普通“已记下”状态，完成周期的词不再抽取。

可在**设置 → 十七天背单词设置**中修改“每组单词数”（默认10）和“每日新增组数”（默认3），各支持1至1000；每天最多新增两者乘积个单词。点击**完成**保存，重启保留，仅影响之后的每日抽词，不改变当天已有批次、旧分组或复习进度。导入学习进度不会覆盖本机这两项设置。

学习页可单独导入导出进度，文件包含参与学习的词条及进度。普通页面也能识别合法学习进度文件，即使本机没有进度，也提供“导入单词和进度”“仅导入单词”“取消”选择；学习页仅接受学习进度文件。

## 获取与启动

前往 [Releases](https://github.com/whyCanNotKK/kkMemorizeVocabulary/releases) 查看可用成品：

- **安装版**：运行 `kkMemorizeVocabulary-Setup.exe`。
- **免安装版**：解压 `kkMemorizeVocabulary-windows-x64.zip`，运行其中的 `kkMemorizeVocabulary.exe`，保留完整文件夹及 `_internal` 目录。

GitHub 的 **Download ZIP** 下载的是源码。根目录的 `BuildInstaller.exe` 用于从源码构建程序，是开发工具。

### 从源码运行

准备 Windows x64 和 Python 3.12 x64，在 PowerShell 中执行：

```powershell
git clone https://github.com/whyCanNotKK/kkMemorizeVocabulary.git
cd kkMemorizeVocabulary
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.lock.txt
.\.venv\Scripts\python.exe main.py --data-dir artifacts\development
```

以上使用隔离的开发数据库。日常使用默认数据目录时，省略 `--data-dir`，或在环境配置好后双击 `start.bat`。

## 常用操作

下方录入区独立保留草稿，切换标签或编辑列表单元格不会要求保存或清空。载入另一主词到下方编辑区时才处理替换确认；主动保存时会保留列表中的独立修改，同部分冲突会提示并保留草稿。

新增词条时使用“清空”，编辑已有词时使用“取消”；确认后才清除未保存输入并返回空白新增表单，已保存词条不变。两种确认框都只提供“确认／取消”，默认聚焦取消，且取消按钮与原操作按钮位置重合，连续误点会取消操作。

十七天学习页的日期/时段行右侧显示“当前单词任务：剩余数/总数”，突出显示剩余数；完成任务只减少剩余数，刷新、重新进入或重启后仍保留当前时段的总数。

列表和新增单词区域的释义编辑框都会随换行、自动折行增高，删短后缩回。列表编辑框不超出可见表格区域，超长时内部滚动；新增区域最多占窗口一半，超出后滚动输入内容。

在底部输入单词、词性和翻译，按 **Ctrl+Enter** 保存，可继续添加释义和关联词。左键单击词名或释义，等待系统双击间隔后复制完整内容（保留换行）；双击或右键单击词名、词性、释义进入编辑，不复制。词性左键单击仅选中，按住拖动调整释义顺序；拖动词名或释义不执行操作。眼睛按钮隐藏或显示当前标签页的答案。

答案被遮住时，左键或右键点击灰色释义遮罩，或其正上方、正下方同一行内的留白，都可显示整组答案；点击范围不向左右扩展，本次点击不进入编辑、不复制。

输入框获得焦点时，光标默认位于内容末尾。双击列表词性会展开以原标签为中心、完整显示全部选项的浮层；点击、1～9、n/v/a或方向键加Enter选择后立即保存并关闭，Esc取消，不再停留在组合框状态。

按住关联词前的折角箭头，可拖动该关联词及全部释义，在同一主词内调整顺序。四个标签页（含搜索结果）及新增/编辑区均支持；列表松开后立即保存，录入区随词条保存。Esc或在关联词范围外松开可取消。

列表中按住已显示的词性标签，可拖动该条词性及翻译，在同一主词或关联词内调整释义顺序，松开后立即保存。四个标签页及搜索结果均支持，沿用相同的让位动画；所有拖动预览均不显示额外边框。Esc或在当前词的释义范围外松开可取消，双击词性仍进入编辑。

录入区每条翻译右侧依次提供拖动柄、圆圈加号和垃圾桶。加号在当前行后插入释义，垃圾桶删除该行，悬停提示当前快捷键；只剩一条时删除置灰。按住拖动柄可在当前词内调整词性和翻译顺序，随词条保存。底部“新增关联词”（Ctrl+N）在当前词后插入，“删除关联词”（Ctrl+M）删除聚焦关联词；主词聚焦时新增插在首位，删除不执行。录入区拥有焦点时显示新增按钮，仅当前操作目标为关联词时显示删除按钮，主词聚焦时隐藏删除按钮；各关联词区域不单独提供“移除”。搜索时隐藏随机排列按钮，清空搜索后恢复。

| 按键 | 操作 |
| --- | --- |
| W / S 或上 / 下箭头 | 列表聚焦时选择上一个 / 下一个主词 |
| 空格 | 非搜索状态下隐藏 / 显示选中词的答案 |
| Alt+1 / 2 / 3 / 4 或 Ctrl+1 / 2 / 3 / 4 | 切换待记 / 全部 / 已记下 / 十七天背单词，保留下方草稿 |
| 回车 | 学习页揭晓 / 记下选中词 |
| F2 | 编辑选中行的释义，隐藏时先揭晓 |
| 编辑时 Tab / Shift+Tab | 保存并切换到下一个 / 上一个单词、词性或释义编辑框 |
| Ctrl+上 / 下箭头 | 只滚动列表，保留选中词 |
| 搜索框↓ / 首个结果↑ | 聚焦第一个结果 / 搜索有内容时回到搜索框继续编辑 |
| Ctrl+Enter | 保存词条或当前单元格修改 |
| Ctrl+E | 显示/隐藏当前标签页所有释义，可在设置中修改；眼睛按钮提示当前快捷键 |
| Ctrl+N / Ctrl+J | 在录入区新增关联词 / 释义 |
| Ctrl+M | 删除当前聚焦的关联词 |
| Ctrl+K | 删除当前聚焦的释义；未聚焦具体释义时不删除 |

常用录入快捷键可在顶部**设置**中修改。搜索覆盖主词、关联词及译文；搜索期间禁用主词拖拽与随机排序。

## 数据与备份

默认数据库为 `%LOCALAPPDATA%\kkMemorizeVocabulary\vocabulary.sqlite3`。**退出程序后复制该文件**，即可完整备份词条、学习进度和设置。更新程序会保留此数据目录。

JSON 用于交换词条或学习进度。普通页面导出当前分类与搜索匹配的全部词条，包括视口外结果。每种文件均只接受本程序实现的当前最新格式（目前词条为 v2、学习进度为 v3），拒绝旧版和未知新版；后续随实际格式升级更新。导入学习进度会替换本机原进度；选择**仅导入单词**可保留原进度。

普通页面在处理草稿和写库前完整校验文件，结构、内容、编码或版本不合法统一提示“数据结构不合法，导入失败”。合法学习进度文件复用已选文件，不二次打开文件选择器；识别与取消不切换标签、不抽词、不改变草稿或数据。恢复进度后重新读取任务，本次不额外抽词。

导入词条的拼写、全部词性和释义、关联词及其释义、重点和已记下状态与本机完全相同时，直接跳过，不出现在重复对比列表，也不计入冲突数量。比较前清理首尾空白，大小写、内部空白和释义/关联词顺序仍须一致；ID和排序号不参与比较。词条相同不影响按用户选择恢复学习进度。

导入、导出处理文件或数据时，整个窗口显示半透明遮罩，中央持续转圈，下方显示当前处理提示。处理期间阻止操作和关闭；文件选择、导入方式选择、重复词对比及结果提示期间可正常操作。重复词采用、批量采用和学习进度导入导出共用此反馈。

可通过 `--data-dir <目录>` 指定其他存储位置，免安装版同样适用。

## 开发与构建

测试使用临时数据库；冒烟检查必须指定隔离数据目录：

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe main.py --smoke-test --data-dir artifacts\source-smoke
```

双击 **BuildInstaller.exe**，或执行：

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

构建会准备依赖、运行测试、打包并校验程序，将安装包和免安装 ZIP 输出到 `dist/`。源码环境准备及首次构建需要联网。

详细行为、架构和数据格式见[项目设计说明](docs/项目设计说明.md)，验证历史见[验收记录](docs/验收记录.md)。
